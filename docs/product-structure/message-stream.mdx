`/main` 中间区域：一条可回溯的「模型思考 → 命令执行 → 结果回喂」对话，不是真人闲聊。

## 内容结构

| 内容单元 | 内容 |
| --- | --- |
| 用户任务 | 用户本次提交的任务文本 |
| 进度摘要 | Agent 当前回合的简短工作说明 |
| 执行详情 | Bash 命令、执行状态、返回码、输出、工作目录、耗时 |
| 最终回答 | Agent 对任务结果的面向用户总结 |
| 运行结果 | 已完成、达到步数上限、已停止或失败 |

## 执行详情字段

- 命令：`$ <command>`。
- 状态：等待执行、执行中、成功、失败、已取消。
- 返回码：`rc`。
- 输出：支持预览、展开完整输出和打开被截断的完整文件。
- 进度摘要和最终回答是文本内容，不把内部推理作为产品结构字段。
