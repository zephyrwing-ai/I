`/main` 是完整的 Agent 工作台：中间消息流，底部输入框。

## 页面区块

| 区块 | 内容 |
| --- | --- |
| 标题栏 | 当前任务标题、运行状态、搜索入口、设置入口 |
| 消息流 | Agent 进度摘要、执行详情、最终回答 |
| 底部输入区 | 多行任务输入、添加入口、发送 / 停止入口 |
| 设置抽屉 | Provider、Model、Base URL、API Key、Docker、Steps 上限、工作目录 |

## 当前版本范围

- 页面以单次 run 为中心。
- 不包含会话列表、历史任务、附件上传或多窗口导航。
- 设置以抽屉形式存在，不作为常驻内容区。
