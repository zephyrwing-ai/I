设置是模型与运行环境的配置内容集合。

| 区块 | 内容 |
| --- | --- |
| 模型连接 | Provider、Model、Base URL、API Key |
| 执行策略 | Docker 沙箱、Steps 上限 |
| 工作目录 | 当前 run 使用的本地工作目录 |


## Provider 内容

- OpenAI / DeepSeek：Model、Base URL、API Key。
- Anthropic（Claude）：Model。
- Google（Gemini）：Model。


## 安全提示

API Key 以掩码显示；完整密钥、运行配置和其他敏感字段不进入对话搜索内容。
