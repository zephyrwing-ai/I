## 对话框

1. 用户在底部输入区输入任务。
2. 用户点击“发送”，或按 `Enter`。
3. 如果任务为空或未选择工作目录，发送不执行，并就地说明原因。
4. 发送成功后创建新的 run snapshot，当前 transcript 清空并进入“连接中”。
5. 连接成功后进入“运行中”，消息流开始追加进度摘要和执行详情。

中文输入法组合态时，Enter 只确认候选，不发送任务；`Shift + Enter` 换行。

## 停止任务

1. 运行中发送按钮变为“停止”。
2. 用户点击“停止”后，界面先进入“正在停止”，禁止重复发送。
3. 后端完成取消后，界面显示“已停止”，保留已经产生的内容和执行证据。
4. “已停止”与系统错误分开表达，不使用同一状态文案。

## 搜索当前 run

1. 用户点击标题栏搜索按钮，或按 `Cmd/Ctrl + F`。
2. 搜索浮层获得焦点。
3. 输入关键词后，在用户任务、进度摘要、命令、输出、最终回答和错误详情中检索。
4. 结果显示匹配数量和当前位置；上下按钮跳转到上一个/下一个结果。
5. 对话流滚动到命中项并短暂高亮；按 `Esc` 关闭并恢复触发按钮焦点。
6. 运行中允许搜索已产生的内容；流式新增内容进入索引后更新数量。

## 失败恢复

- API Key 或 Provider 错误：显示具体原因，点击“检查设置”打开设置抽屉并聚焦相关字段。
- 网络或模型错误：提供“重试”，复用任务文本和当前配置草稿，创建新的 run snapshot。
- 命令失败：保留失败命令、返回码和输出；允许复制命令或重新运行整个任务。
- 达到 Steps 上限：保留证据，提示提高上限后重试。
