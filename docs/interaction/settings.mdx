## 打开与关闭

1. 用户点击标题栏右侧“设置”。
2. 右侧设置抽屉展开；焦点进入抽屉标题或第一个可编辑字段。
3. 用户点击关闭、按 `Esc` 或点击外部区域关闭抽屉。
4. 关闭后焦点返回设置按钮；未发送的配置草稿保留。

## 修改配置

- Provider 切换后显示对应的 Model 和连接字段。
- Base URL、API Key、Model、Docker、Steps 上限和工作目录属于下一次 run 的配置草稿。
- 运行中的任务可以查看设置，但字段只读，并显示“当前运行配置已锁定”。
- 工作目录未选择时，发送按钮不可用，并提示先选择目录。
- Steps 上限限制在 1–100，非法输入在字段附近说明原因。

## 配置错误

- API Key 缺失、无效或网络连接失败时，错误显示在相关字段或错误摘要附近。
- 点击“检查设置”后，抽屉打开并将焦点移动到需要处理的字段。
- 修正后点击“重试”创建新的 run，不修改旧 run 的执行记录。
