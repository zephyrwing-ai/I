本目录定义用户动作、系统响应、状态变化和反馈文案。它不重复产品结构表，也不规定颜色、图标或像素尺寸。

## 交互入口

- [主工作台](./main-workspace) — 任务输入、运行、停止、搜索和恢复。
- [消息流](./message-stream) — 进度、执行详情、输出和最终回答。
- [设置](./settings) — 设置抽屉、配置修改和运行锁定。

## 通用状态原则

- 状态必须通过文字和语义图标表达，不能只依赖颜色。
- 用户主动停止显示“已停止”，不显示成“失败”。
- 失败保留错误原因，并在原上下文提供下一步动作。
- 当前 run 的设置是快照；修改设置只影响下一次 run。
