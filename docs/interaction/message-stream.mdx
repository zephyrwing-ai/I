## 模型内容与工作状态

1. 空闲状态下，消息流展示此前的对话内容。
2. 新回合开始时显示模型内容占位；模型增量内容到达后持续追加。
3. 模型运行期间显示 `Working for + 已运行时长`。文字使用字形扫光，右侧显示朝右的展开箭头，摘要行下方使用细分隔线与正文区分。
4. 扫光只在文字笔画内部移动；文字、箭头、分隔线和摘要行背景均保持静止。减少动态效果模式下使用静态低强调文字。
5. 运行完成后状态改为静态 `Worked for + 总时长`，不再播放扫光。
6. 模型持续运行，直到任务不再需要工具调用并生成最终回答。
7. 用户将鼠标移入或使用键盘聚焦最终回答后，回答下方显示复制动作和模型开始回复的时间；时间使用带 `AM/PM` 的本地格式。

## 执行详情

- 用户点击 `Working for / Worked for` 摘要行后，在原位置展开或收起本次运行的内联活动流。
- 第一层展开内容包含模型进度说明和工具活动摘要，直接插入正文流，不渲染成独立卡片。
- 多个连续工具调用归入一个工具组。用户点击工具组后展开调用列表；每次工具调用拥有独立的二级展开状态。
- 单次工具调用展开后显示参数、命令、工作目录、状态、耗时、返回码和输出。
- 活动流从结构化运行事件派生，包括 `tool loaded`、`search`、`read file`、`run command`、`edit file` 和 `create file`。前端不得从自然语言正文猜测工具类型。
- 运行中默认展开第一层活动流；运行完成后默认收起，但保留用户主动设置的展开状态。
- 搜索命中折叠详情时，临时展开命中上下文，但不永久改变用户的折叠偏好。

## 滚动策略

- 用户位于底部时，流式更新自动跟随最新内容。
- 用户主动向上阅读历史时，暂停自动抢焦点，并提供“回到最新”入口。
- 完成、失败或停止时，滚动到结果摘要，但不覆盖用户正在查看的历史位置。
