## 回合推进

1. 新回合开始时显示进度摘要占位。
2. 模型增量内容到达后，进度摘要持续追加并保持视口跟随最新内容。
3. 模型决定执行命令后，执行详情组出现；命令依次经历“等待执行 → 执行中 → 成功 / 失败 / 已取消”。
4. 命令结果包含返回码和输出；结果回喂模型后进入下一回合。
5. 不再产生命令时，显示最终回答和运行结果摘要。

## 执行详情

- 执行详情默认收敛显示，展开后查看命令、工作目录、耗时、返回码和输出。
- 搜索命中折叠详情时，临时展开命中上下文，但不永久改变用户的折叠偏好。
- 输出超过阈值时先显示预览和字符数；存在完整文件时提供打开入口。
- `rc=0` 显示成功；非零返回码显示失败并使用对应恢复动作。

## 滚动策略

- 用户位于底部时，流式更新自动跟随最新内容。
- 用户主动向上阅读历史时，暂停自动抢焦点，并提供“回到最新”入口。
- 完成、失败或停止时，滚动到结果摘要，但不覆盖用户正在查看的历史位置。
