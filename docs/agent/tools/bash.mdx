---
title: Bash
description: Agent 执行本机终端命令和运行本地文件的通用工具。
---

Bash 是 Agent 的通用终端能力。模型可以用它查看环境、调用系统命令、运行本地脚本、安装依赖、构建项目和执行测试。

## 调用

一次调用包含需要执行的命令和可选的超时时间。Execution 为每次调用启动独立的本机 Bash 命令进程，初始目录来自当前 run 的工作目录。

Bash 不是持续存在的交互式终端会话。某次调用中执行的目录切换和临时环境变量不会自动保留到下一次调用；需要连续状态时，模型应在同一条命令中表达完整操作，或在下一次调用中再次指定状态。

## 结果

执行期间持续收集标准输出和标准错误，并通过工具事件发送增量结果。调用完成后返回输出、返回码、耗时、超时或取消状态；输出过长时返回截断标记和受控临时文件位置，具体展示方式由宿主决定。

返回码非零属于工具错误，会连同已经产生的输出一起回填模型。用户停止时，执行器终止当前命令及其子进程，不能让后台进程在 run 结束后继续运行。

## 能力边界

工作目录只是命令的初始目录，不是权限边界。Bash 使用启动应用的用户权限，可以访问该用户原本有权限访问的路径，也可能修改文件。产品不能把 Bash 描述为沙盒、受限终端或只读能力。

Bash 可以通过系统命令完成文件读取、搜索和修改，但专用文件工具仍用于高频操作，以减少命令拼接、转义错误和不可预测输出。Bash 工具不提供持续 Shell 会话或交互式终端输入，每次调用都是独立执行单元。
