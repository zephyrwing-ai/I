title: Bash
description: Agent 执行本机终端命令和运行本地文件的通用工具。

Bash 是 Agent 的通用终端能力。模型可以用它查看环境、调用系统命令、运行本地脚本、安装依赖、构建项目和执行测试。

## 调用

当前模型调用只包含非空字符串 `command`，注册的 Bash 工具固定传入30秒超时，不支持模型指定超时时间。Execution 为每次调用启动独立的本机 `bash -c` 进程，初始目录来自当前 run 的工作目录。执行环境内部已有 timeout 选项，尚未作为模型工具参数开放。

Bash 不是持续存在的交互式终端会话。某次调用中执行的目录切换和临时环境变量不会自动保留到下一次调用；需要连续状态时，模型应在同一条命令中表达完整操作，或在下一次调用中再次指定状态。

## 结果

当前执行期间将标准输出和标准错误收集到内存，在命令完成后一次性返回，不发送工具输出增量。结果包含输出、返回码、截断标记，以及可选错误和文件产物；没有耗时或独立的超时、取消字段。

输出超过10,000字符时，将完整输出写入内部临时文件，回传最后6,000字符和截断提示。完整输出路径用于模型上下文，不随公共工具结果直接发往 Renderer。每条命令前后会对工作目录做有上限的快照比较以发现文件产物；这是文件发现机制，不是权限隔离，也不能保证发现所有变化。

返回码非零属于工具错误，会连同已经产生的输出一起回填模型。当前用户停止时仅向直接 Bash 进程发送 SIGKILL，未实现对整个后代进程树的可靠终止。终止整个进程组、为超时和取消提供明确诊断、让目录快照响应取消均为待完善目标。

## 能力边界

工作目录只是命令的初始目录，不是权限边界。Bash 使用启动应用的用户权限，可以访问该用户原本有权限访问的路径，也可能修改文件。产品不能把 Bash 描述为沙盒、受限终端或只读能力。

Bash 可以通过系统命令完成文件读取、搜索和修改；当前已经注册的 Read、Write、Edit 与 Query 工具承担这些高频操作的结构化语义，减少命令拼接、转义错误和不可预测输出。Bash 工具不提供持续 Shell 会话或交互式终端输入，每次调用都是独立执行单元。Bash 的持久化恢复策略为 `never`，由恢复协调器保存执行现场并等待状态确认，详见[工具执行恢复](./recovery.mdx)。
