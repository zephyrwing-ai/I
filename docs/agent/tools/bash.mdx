Bash。

- 能力：为 Agent 提供本机通用终端命令，覆盖环境查看、系统命令、本地脚本、依赖安装、项目构建和测试执行。
- 定位：通用终端能力处理长尾任务；已注册的 Read、Write、Edit 与 Query 为高频文件操作提供结构化语义，减少命令拼接、转义错误和输出差异。

调用。

- 参数：模型提交非空字符串 `command`；注册工具固定传入30秒超时，执行环境内部的 `timeout` 选项属于宿主配置，模型参数保持为 `command`。
- 进程：Execution 为每次调用启动独立的本机 `bash -c` 进程，初始目录来自当前 run 的工作目录。
- 状态：目录切换和临时环境变量作用于本次独立调用；连续操作在同一条命令中表达完整状态，后续调用重新指定所需状态。
- 交互：每次调用构成独立执行单元，持续 Shell 会话与交互式终端输入属于后续能力。
- 权限：Bash 使用启动应用用户的本机权限，能够访问该用户有权访问的路径并执行文件修改；工作目录承担初始目录职责，权限范围沿用操作系统用户权限。

结果。

- 收集：标准输出和标准错误在执行期间收集到内存，命令完成后一次性返回整体结果。
- 字段：结果包含输出、返回码、截断标记，以及可选错误和文件产物；耗时与独立超时、取消字段属于后续诊断扩展。
- 长输出：输出超过10,000字符时，完整输出写入内部临时文件，模型收到最后6,000字符和截断提示。
- 完整输出路径：进入模型上下文，Renderer 接收公共工具结果字段。
- 文件发现：命令执行前后对工作目录进行有上限的快照比较，发现范围由快照覆盖范围决定；访问权限沿用 Bash 进程的操作系统权限。
- 非零返回码：形成工具错误，已产生的输出共同回填模型。

取消与恢复。

- 当前停止：用户停止时向直接 Bash 进程发送 SIGKILL，后代进程的结束状态由各进程实际执行情况决定。
- 后续完善：通过进程组终止覆盖命令后代，为超时和取消提供独立诊断，并让目录快照响应取消信号。
- 恢复策略：使用 `never`，恢复协调器保存执行现场并等待状态确认；具体规则见[工具执行恢复](./recovery.mdx)。
