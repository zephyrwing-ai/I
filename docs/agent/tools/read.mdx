Read 用于读取一个明确文件，不修改文件内容。它为模型提供稳定的文件语义，避免模型为常规读取反复拼接 `cat`、`sed` 或临时脚本。

## 调用

一次调用包含文件路径，并可指定开始行和最大读取行数。相对路径以当前 run 的工作目录解析；绝对路径仍受启动应用用户的本机权限约束。

文本文件按行返回。大文件不会无边界进入模型上下文；结果标明已经读取的范围、是否截断以及继续读取时应使用的下一起始行。模型需要完整文件时，通过后续 Read 调用继续读取。

模型支持的图片文件作为图片内容返回，而不是把二进制数据打印成文本。无法识别或无法读取的文件返回明确错误。

## 结果与边界

结果包含实际读取的内容和必要的截断信息，同一结果进入模型上下文与运行事件。Read 不运行 Shell，不创建文件，也不改变文件；工作目录仍只是路径解析起点，不构成沙盒。
