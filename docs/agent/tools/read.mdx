Read。

- 状态：已实现并注册，定义与执行位于 `agent/tools/read.ts`。
- 职责：读取明确文件，提供稳定的文件语义，让常规读取直接使用结构化接口。
- 权限：文件操作保持只读，相对路径以当前 run 的工作目录解析，绝对路径沿用启动应用用户的本机权限；工作目录承担路径解析起点职责。

调用。

- 参数：提交文件路径，可选开始行和最大读取行数。
- 文本：按行返回文件内容，读取范围受调用参数与工具容量边界约束。
- 续读：结果标明实际范围、截断状态和下一起始行；模型通过后续 Read 调用获取后续内容或完整文件。
- 图片：模型支持的图片文件作为图片内容返回，二进制数据沿图片协议传递。
- 错误：文件识别失败或读取失败时返回明确错误。

结果。

- 内容：包含实际读取内容和必要的截断信息，同一结果进入模型上下文与运行事件。
- 执行：Read 直接完成文件读取，源文件内容和目录结构保持原状。
