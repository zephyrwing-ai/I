---
title: Write
description: Agent 创建文件或用完整内容覆盖文件的工具。
---

Write 用于创建文件，或使用调用中提供的完整内容覆盖已有文件。它表达的是整文件写入，不负责局部替换，也不提供追加模式。

## 调用

一次调用包含目标路径和完整文件内容。目标目录不存在时创建必要的父目录；目标是目录或无法写入时返回错误。同一文件的 Write 与 Edit 共享修改顺序，避免并发写入互相覆盖。

覆盖已有文件属于真实副作用。模型在无法确定现有内容是否应被替换时必须先调用 Read；可以通过 Edit 完成的局部修改不应使用 Write 重写整个文件。

## 结果

成功结果确认实际写入的路径和内容大小，失败结果保留文件系统返回的原因。写入结果进入模型上下文和运行事件，使后续模型请求能够确认操作已经完成，而不是重复执行同一写入。
