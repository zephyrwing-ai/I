Edit 用于修改已有文本文件中的一个或多个明确片段。它适合局部改动，不要求模型重写整个文件，也不依赖 `sed`、正则替换或临时脚本。

## 调用

一次调用包含文件路径和一组“原文本 → 新文本”替换。每段原文本必须在调用开始时的文件内容中唯一匹配，各段替换不能重叠。多个替换都以同一份原始内容为基准，不能依赖前一个替换产生的中间状态。

只要任一目标不存在、不唯一、相互重叠或文件不是可编辑文本，整次调用就失败，不能写入部分结果。同一文件的并发修改按顺序执行，避免两个工具调用相互覆盖。

## 结果

写入时保留原文件的换行风格和必要的文件头信息。成功结果包含修改数量、变更摘要、结构化差异以及第一处变更位置；失败结果说明具体未满足的条件。

Edit 只负责精确局部替换。创建新文件或整体重写文件使用 [Write](./write.mdx)，不确定修改目标时应先使用 [Read](./read.mdx) 获取最新内容。
