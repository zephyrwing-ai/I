Query 是本地工作区的结构化只读查询能力，由列出目录、查找文件和搜索内容三种工具组成。相同任务可以通过 Bash 命令完成，但专用查询工具提供固定参数、统一忽略规则、结果上限和明确的活动语义。

## 列出目录

列出目录接收可选路径和结果数量上限，默认查询当前 run 的工作目录。结果按名称稳定排序，并区分文件和目录；空目录、路径不存在和目标不是目录分别返回明确结果。

## 查找文件

查找文件接收文件名或路径匹配规则、可选搜索目录和结果数量上限。结果返回相对于搜索目录的路径，并遵循项目忽略规则，避免默认进入依赖目录和版本控制内部目录。结果达到数量或大小上限时必须明确标记，不能让模型误以为已经遍历全部文件。

## 搜索内容

搜索内容接收搜索文本或正则、可选目录、文件类型过滤、大小写规则、上下文行数和结果数量上限。结果包含文件路径、行号和匹配内容；达到匹配上限或单行被截断时明确提示。

Query 不修改文件，也不获得额外网络能力。网页搜索不是本地 Query 的一部分，后续需要单独实现并注册网页搜索工具。
