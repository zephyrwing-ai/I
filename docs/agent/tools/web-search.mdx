网页搜索。

- 工具：`web_search` 使用公共搜索入口查找网页，基础注册表向桌面端和 CLI 提供同一能力。
- 搜索源：DuckDuckGo 非 JavaScript HTML 搜索页通过原生 HTTP 请求接入，公开入口提供搜索结果，现有模型连接承担工具调用与后续回答。
- 查询：`query` 保存搜索词，`maxResults` 限定本次返回数量；模型调用按既有公共 schema 填写用户语言的 `purpose` 和关联 `targets`。
- 说明：公开 `content` 与工具 `purpose` 进入共享 commentary 投影，工具组标题与操作行由网页搜索类别和真实查询参数生成。
- 结果：按搜索页顺序提供网页标题、真实 URL 与原始摘要；请求返回内容通过 DOM 解析器提取为结构化结果。
- 模型输出：`output` 包含查询和各网页的标题、链接及搜索摘要，Runtime 按现有 Tool Message 规则交给模型续轮。
- 展示数据：`web.pages` 与文本输出来自同一次搜索，结构化字段随工具结果持久化，实时与历史共用校验及公共投影。
- 请求边界：固定搜索源、受控响应大小、请求超时与运行取消共同限定一次工具执行。
- 失败：服务验证、访问限制、请求失败与未知页面结构分别形成可读工具错误；搜索页明确表达空结果时返回成功的空列表。
- 恢复：结果落库后可供后续读取；已计划调用采用显式恢复策略，运行取消沿用既有持久化事实。
