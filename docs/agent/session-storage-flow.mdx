这组流程描述项目历史和无项目历史的统一提交边界。`projectId` 为真实项目 ID 时，消息归入该项目；`projectId = NULL` 时，消息归入无项目历史。

## 参与者职责

- Electron Main 打开 `userData/agent-sessions.sqlite`，维护项目注册表和项目上下文缓存。
- AgentRunner 为每次用户提交创建 `runId`，捕获 `projectId`、`cwd`、HistoryRecorder 和瞬时项目上下文。
- Runtime Loop 控制用户消息、助手消息和工具结果的提交顺序。
- HistoryRecorder 维护已完成消息快照、流式助手草稿、工具恢复账本和串行 SQLite 写入队列。
- SQLite 保存 `projects`、`project_context`、`entries` 和 `tool_invocations`。
- Renderer 接收 AgentEvent、项目切换结果和历史分页结果。

## 单次运行流程

```mermaid
sequenceDiagram
    participant Composer
    participant Main
    participant ProjectRegistry
    participant HistoryRecorder
    participant SQLite
    participant Runtime
    participant Model

    Composer->>Main: task + modelOptionId + projectId
    Main->>ProjectRegistry: 读取当前项目和 project_context
    ProjectRegistry->>SQLite: 读取项目元数据与目录缓存
    SQLite-->>ProjectRegistry: 项目描述与有界目录树
    Main->>HistoryRecorder: 取得 projectId 范围的 Recorder
    HistoryRecorder->>SQLite: 读取当前范围 completed entries
    SQLite-->>HistoryRecorder: 有序 ModelMessage 快照
    Main->>Runtime: 注入 HistoryRecorder + project_context + runId
    Runtime->>HistoryRecorder: commitUser(userMessage)
    HistoryRecorder->>SQLite: 追加 project_id 范围的 user_message
    HistoryRecorder-->>Runtime: 本地提交完成
    Runtime->>Model: history + project_context + userMessage

    loop 模型增量
        Model-->>Runtime: text_delta / reasoning_delta
        Runtime->>HistoryRecorder: recordAssistantDelta(delta)
        HistoryRecorder->>SQLite: 合并刷新 assistant 草稿
    end

    Model-->>Runtime: completed(content, reasoning, toolCalls)
    Runtime->>HistoryRecorder: finishAssistantAttempt(...)
    HistoryRecorder->>SQLite: 提交 assistant_message

    alt 存在工具调用
        Runtime->>HistoryRecorder: registerToolInvocation(...)
        Runtime->>Runtime: 执行工具
        Runtime->>HistoryRecorder: commitToolResult(toolMessage)
        HistoryRecorder->>SQLite: 追加 tool_result 与恢复状态
        Runtime->>Model: 使用当前范围历史继续请求
    else 直接回答
        Runtime->>HistoryRecorder: finishRun(completed)
    end
```

## 历史恢复流程

```mermaid
flowchart TD
    start[应用启动] --> open[打开 agent-sessions.sqlite]
    open --> scope[选择 projectId 或 NULL 历史范围]
    scope --> entries[按 project_id 查询 entries]
    entries --> ordered[按 entry_order 升序恢复]
    ordered --> recorder[创建 HistoryRecorder]
    recorder --> page[Renderer 加载当前范围历史]
    page --> request[下一次运行加入 project_context 与新任务]
```

历史快照只包含已完成的用户消息、助手消息和工具结果。流式记录在恢复时继续保留已写入内容，并由 Recorder 处理终态。

## 项目上下文流程

- 项目首次激活时，Main 扫描有限目录结构并写入 `project_context`。
- 缓存保持 clean 时，下一次运行直接读取缓存。
- 工具写入项目文件后，Main 将缓存标记为 dirty。
- 下一次运行刷新缓存，并以相同的有界格式把目录树加入模型请求。
- 项目上下文作为 transient ModelMessage 进入 Runtime，entries 保存用户与模型事实。
- 无项目历史拥有独立的 `NULL` 范围，并使用历史和当前任务构造模型请求。
