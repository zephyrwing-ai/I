## 数据存储

- [x] 创建 `projects` 表，保存 `projectId`、规范化路径、显示名称和最近激活时间。
- [x] 创建 `project_context` 表，保存有界目录树、hash、扫描策略和 dirty 状态。
- [x] 将 `entries` 改为 nullable `project_id` 范围和全局 `entry_order`。
- [x] 将 `tool_invocations` 改为 nullable `project_id` 范围，并使用 `run_id + tool_call_id` 关联工具调用。
- [x] 增加旧 sessions 数据迁移，将既有历史归入无项目范围。

## HistoryRecorder 与 Runtime

- [x] 将持久化契约命名为 `HistoryRecorder`。
- [x] 保持用户消息、助手草稿、完整助手消息、工具结果和恢复账本的提交屏障。
- [x] 以 `projectId: string | null` 绑定 Recorder 历史范围。
- [x] 将项目上下文作为 transient Runtime context 注入模型请求。

## Main 与 IPC

- [x] Main 管理项目目录规范化、项目创建、项目恢复和无项目范围。
- [x] Preload 暴露 `getActiveProject`、`selectProject`、`clearProject` 和 `loadHistoryPage`。
- [x] Main 按项目范围创建和缓存 HistoryRecorder。
- [x] 项目切换在运行空闲时更新历史、Canvas 和目录上下文范围。

## Renderer 与 Composer

- [x] Composer 顶部提供项目选择行。
- [x] 空状态显示 `Choose folder`，项目状态显示目录名称。
- [x] 项目选择行使用圆润的 `folder-closed` 图标。
- [x] 项目切换后重新加载对应历史投影。
- [x] 项目选择和清除在运行期间保持禁用。
