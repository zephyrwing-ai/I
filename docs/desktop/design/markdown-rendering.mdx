文本渲染与标点规范化。

- 渲染入口：独立公开过程说明 `TurnState.progressContent` 与最终答案 `assistantContent` 共用 `frontend/src/middle-column/message-stream/MarkdownText.tsx`；ReactMarkdown 先解析 mdast，`punctuation-md.ts` 再遍历 text 节点完成标点规范化，随后渲染 React 元素。每个回合及最终回合的过程说明位于外层活动折叠内，最终答案位于折叠外，排布遵循[消息流](./workbench/message-stream.mdx)。
- Markdown 扩展：`remark-gfm` 提供表格、删除线和任务列表；`remark-breaks` 将单个换行渲染为 `<br>`，保持消息区连续行的节奏。
- 行内呈现：`strong`、`em`、`del` 直接渲染子内容，配对的 `**加粗**`、`*斜体*`、`~~删除线~~` 以纯文本呈现；列表、标题、表格、代码块和引用保留各自结构。
- 原始数据：`agent/loop.ts`、IPC 和 `agentReducer` 聚合、传递并保存原始文本，Renderer 负责展示规范化与结构转换。模型答案复制保留原文；用户消息复制使用下述显示文本。会话导出属于独立的后续能力。
- 通道来源：Adapter 按响应起始 V1 行帧解析公开说明与最终正文，协议标记由 Adapter 消费，MarkdownText 接收对应字段中的正文文本。原始 reasoning 保存在独立状态、历史与 Provider 续轮字段中；公开说明由主模型同次任务响应独立生成。
- 语言与兼容：通道身份由协议和字段确定，展示规范化在字段确定后处理文本；中文、英文及混合内容使用相同通道映射。普通正文响应和旧记录沿用既有 `content` 渲染，等待与说明缺失状态由消息流的固定状态文案表达。

标点规范化。

- 启用范围：展示规范化默认生效，中文标点使用英文半角并按规则补空格，例如 `你好，世界。` 显示为 `你好, 世界.`。
- 模型 Markdown：逐个处理 text 节点；含汉字的节点执行全角映射，全部 text 节点执行补空格遍历。全英文节点保留原有标点形态并参与空格处理。
- 用户气泡：`normalizePunctuation` 先判断整个字符串；纯英文任务原样返回，含汉字任务处理三反引号围栏以外的区段。气泡以纯文本显示，三反引号围栏提供字符串级代码保护。
- 节点作用域：中文与标点分属不同 Markdown 节点时，标点映射依所在 text 节点的汉字检测结果决定；两条路径共享规则常量，保留各自的检测范围与代码保护粒度。
- 逗号映射：全角逗号 `，` 和顿号 `、` 转为半角逗号 `,`。
- 句末映射：`。` 转为 `.`，`！` 转为 `!`，`？` 转为 `?`。
- 分隔映射：`；` 转为 `;`，`：` 转为 `:`，`～` 转为 `~`，`％` 转为 `%`。
- 括号映射：`（ ）` 转为 `( )`，`【 】` 转为 `[ ]`。
- 引号映射：中文双引号转为 ASCII 双引号，中文单引号转为 ASCII 单引号。
- 补空格：半角 `, . ; : ! ?` 后补一个 ASCII 空格；已经存在空格、后接相邻标点或闭合括号时保留现有分隔，例如 `好的, 然后.` 和 `…)`。
- 词内保护：前后均为字母、数字或下划线的标点保持原样，例如 `3.14`、`1.2.3`、`10:30`、`package.json`、`goo.gl`；URL 和路径中的分隔保持原样，例如 `https://example.com`。
- 引号间距：引号前按同一补空格规则处理，例如 `他说: "你好"`。
- 结构保护：围栏代码块和行内代码按 mdast 节点类型保留原文；链接地址与图片地址位于节点属性，保留原始地址。表格单元格和任务列表中的 text 节点沿用文本规则。
- 节点边界：补空格时读取同一父节点下后续兄弟节点的下一可见字符，例如 `你好,**世界**` 按“世”判断间距，`10, **30**` 沿用词内保护；跨层级可见文本查找属于后续规则统一范围。
- 围栏结束：开放的三反引号围栏按 CommonMark 规则延续到文末，整个代码块保留原文。
- 强调边界：配对标记经解析后显示纯文本；奇数个星号或被空行拆散的标记按普通字符显示；代码节点里的标记按源码显示。
- 用户代码：用户任务中的行内反引号和普通粘贴代码沿用字符串级文本规则，含汉字任务可触发这些区段的标点转换；用户气泡的 Markdown 展示属于独立的后续产品决策。

实现与显示。

- Markdown 规则：`frontend/src/utils/punctuation-md.ts` 的 `normalizeMdast` 遍历 text 节点，`firstVisibleChar` 提供同级可见字符查找。
- 字符串规则：`frontend/src/utils/punctuation.ts` 提供用户气泡与复制行使用的纯函数；映射表、补空格集合与词内保护常量由两条路径共享。
- 组件：`MarkdownText.tsx` 使用 Memo 包裹；外链设置 `target="_blank"` 和 `rel="noopener noreferrer"`，Main 的 `setWindowOpenHandler` 交给系统浏览器；表格通过 `.md-table-wrap` 独立横向滚动。
- 结构样式：`frontend/src/middle-column/message-stream/message-stream.css` 统一管理 `.markdown`，相邻基础块间距8px，标题、列表、表格、代码块、引用和分隔线的上下间距各12px。
- 代码显示：代码块宽度跟随内容列，使用16px圆角、表面填充和边框；围栏代码保留空格与换行，按可用宽度软折行，连续长 token 在需要时折行。
- 其他结构：表格使用细边框与独立滚动；任务列表使用只读复选框，链接保留下划线，标题和列表沿用结构排版。
- 模型复制：`AssistantMessage` 将最终回答的 `assistantContent` 原文交给 `MessageMeta`，保留 Markdown 标记与原始标点。
- 用户复制：`MessageStream` 将规范化的 `taskText` 同时交给气泡和 `MessageMeta`，当前复制内容与界面显示一致；复制任务原文的后续契约通过调整该传值接入。
- 交互边界：静态结构渲染覆盖文本、代码保护与链接属性；浏览器布局、点击、剪贴板权限和系统浏览器打开由对应界面与宿主交互负责。
