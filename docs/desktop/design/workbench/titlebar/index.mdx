标题栏。

- 入口：右侧操作组由工作侧栏与搜索组成，工作目录文件与 Canvas 使用[侧栏入口页](./sidebar/index.mdx)提供。
- 位置：工作台内框顶部，中间列至右侧边缘共同形成主标题区域；右端提供工作台操作按钮组，项目模式且列表收起时左端提供展开按钮，侧栏开合期间右端按钮保持内框位置。
- 尺寸：每个按钮热区30乘30px，按钮之间间距4px；按钮组沿用透明共用区域。
- 位置坐标：纵向居中于内框标题行，右端按钮组使用共同水平内边距；尺寸来源见[设计令牌](../tokens.mdx)。
- 材料：共用区域保持透明，按钮沿用透明背景，悬停和激活状态使用悬停反馈颜色。
- 布局：主标题栏占据内框标题行，项目标题与它位于同一水平基线；消息主列和右侧工作侧栏使用下一行的剩余高度，项目列表正文使用自身标题下方的空间。
- 模式：标题栏随 App 的 `selectedView` 呈现普通对话或项目视图；普通模式保留右侧工作台操作组，项目模式呈现标题分隔线与项目开合入口。
- 列表开合：项目模式下，列表收起时主标题栏左端显示 `projects-sidebar-toggle`，名称为 `Show projects`；列表展开时，同一操作入口位于项目标题的 `＋` 右侧，名称为 `Hide projects`。按钮沿用30乘30px热区，`aria-expanded` 与 `aria-controls="projects-panel"` 描述列表状态。
- 拖拽：内框标题行使用 `-webkit-app-region: drag`，按钮使用 no-drag 响应交互；左侧导航维护外壳拖拽区，项目标题维护项目列标题热区。消息自绘滚动条使用内容行中局部消息视口的独立热区。
- 区域边界：项目模式在标题行下边缘使用2px `--workbench-resizer-emphasis` 分隔线，普通模式的标题区与消息区使用连续表面；内框外边缘及左右侧栏内部边缘继续使用工作台分隔颜色，边框与 `pointer-events: none` 伪元素保持各自的点击与拖拽命中区域。
- 结构：标题栏只定义操作入口的排列与共同视觉规则；每个入口的交互和展开内容由对应文档定义。
- 语义：单一标题主工作台仅供屏幕阅读器使用，可见区域呈现工作台内容。

操作入口。

- 左端：[项目列表开合](../project-navigation.mdx)，在项目模式且列表收起时显示。
- 右侧第一位：[工作侧栏](./sidebar/index.mdx)，按活动范围打开侧栏入口页。
- 右侧第二位：[全局搜索](./search.mdx)。
- 侧栏入口页：[工作目录文件](./sidebar/project-files.mdx)由具体项目提供，[Canvas](./canvas.mdx)由当前普通或项目范围提供。
- 设置入口归属于左侧项目导航，详见[设置](./sidebar/settings.mdx)。
