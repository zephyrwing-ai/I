标题栏（右上角悬浮按钮组）。

- 位置：窗口右上角，固定悬浮于内容之上，不随右侧侧栏开合移动；右侧侧栏展开时按钮组继续位于侧栏之上。
- 尺寸：每个按钮热区30乘30px，按钮之间间距4px；按钮组没有背景容器。
- 位置坐标：纵向居中于顶部52px条带，按钮组右缘距离窗口右侧12px。
- 材料：不绘制背景、边界与阴影；按钮自身为透明背景，悬停和激活状态使用悬停反馈颜色。
- 布局：消息主列和右侧工作侧栏均从窗口顶部开始、纵向贯穿全高；顶部52px为透明拖拽层，叠在内容之上，不占独立背景条，也不为主列保留起始高度。
- 拖拽：条带整体为窗口拖拽区域（`-webkit-app-region: drag`），按钮使用 no-drag 保持可点击；拖拽层覆盖内容顶部52px，该区域内不响应点击与文本选择，消息自绘滚动条位于拖拽层之上以保证顶部滑块可抓取。
- 结构：标题栏只定义操作入口的排列与共同视觉规则；每个入口的交互和展开内容由对应文档定义。
- 语义：单一标题主工作台仅供屏幕阅读器使用，视口中不显示文字标题。
