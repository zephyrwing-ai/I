右侧工作侧栏。

- 交互状态：普通范围入口、项目入口、项目文件树、普通资源列表、资源预览、Canvas 和侧栏拖拽已经接入。
- 页面分工：左侧导航轨道提供 `I / Project / Settings`，左侧项目列表展示已登记项目，中间承载消息与 Composer，右侧承载当前范围的入口和内容。
- 范围身份：普通范围使用 `projectId = null`，项目范围使用稳定 `projectId`；当前范围共同决定入口卡片、目录实例、资源列表、Canvas 文档和历史上下文。
- 项目默认激活：点击左侧 Project 入口后，前端按项目列表当前显示顺序激活第一项；同一项目描述同步更新左侧选中态、中间历史、Composer、右侧入口和 Canvas 范围。
- 切换反馈：默认项目选择和显式项目选择共用范围切换流程；等待期间展示加载状态，失败时提供重试并保留原范围内容。

入口页。

- 打开：点击标题栏右端的工作侧栏按钮后，右侧壳体展开并显示当前范围入口页。
- 项目选项：项目范围提供 `Open workspace files` 与 `Open canvas` 两张等宽卡片，卡片组在右侧可用区域横向和纵向居中。
- 普通选项：普通范围在侧栏左上角依次纵向排列 `View All Outputs` 与 `Open Canvas` 两个胶囊按钮，资源列表接在下方；存储位置按钮打开 Main 管理的附件目录。
- 普通入口样式：两个按钮共享次级表面、30px最小高度、13px共享英文字体与500字重，SVG为18px透明底图标；布局与资源规则见[普通资源视图](./resources.mdx)。
- 文案：入口使用图标和单一标题，范围名称与项目路径由左侧导航、项目列表和 Tooltip 提供。
- 项目卡片尺寸：整张卡片为按钮热区，最小高度72px、内边距12px、圆角12px；左侧图标区44×44px、圆角8px。
- 项目卡片材料：默认使用 `--surface` 背景、1px通用边界和主要文字颜色；悬停使用 `--hover`。
- 项目画布图标：`Open canvas` 使用 line-squiggle 图标24px、2px描边和圆角端点。
- 工作目录图标：`Open workspace files` 使用 folder 图标24px，与画布卡片共享尺寸、圆角和悬停反馈。
- 图标轴：项目范围的两张卡片使用28px左内边距、44px图标列和12px图标文字间距，两个图标与两段文案分别共享同一起始轴线。
- 交互：卡片通过 Tab 聚焦并使用 Enter 或 Space 激活；点击画布切换到 Canvas 表面，点击工作目录切换到文件表面。

内容表面。

- 状态空间：右侧当前表面使用 `home`、`files`、`canvas`、`resource` 四类状态；`null` 表示整个侧栏壳体收起。
- 项目文件：文件表面展示当前项目的目录树，工具栏、刷新、筛选、分页与项目文件访问规则见[项目文件视图](./project-files.mdx)。
- 普通资源：资源入口和资源预览规则见[普通资源视图](./resources.mdx)。
- Canvas：Canvas 表面使用当前范围的项目文档与保存链路，规则见[Canvas](../canvas.mdx)。
- 返回：Canvas、资源预览与项目文件表面左上角统一提供浮动返回按钮。
- 浮动返回按钮：30×30px、8px圆角、半透明表面、12px背景模糊和轻阴影；悬停使用 `--hover` 与主要文字颜色。
- 表面切换：入口页和当前内容表面共用同一个侧栏壳体、宽度、拖拽条和开合动画。

工作侧栏按钮。

- 位置：内框主标题栏右端操作组第一位，搜索入口位于其右侧。
- 名称：Tooltip 与无障碍名称使用 `Show sidebar` 或 `Hide sidebar`。
- 交互：按钮在侧栏收起时展开入口页，在侧栏展示期间收起整个右侧壳体。
- 图标：18×18px的 `sidebar` 与 `sidebar-collapsed` 图标，外框圆角4px、描边2px；收起态使用靠右、上下内缩、圆角端点的3px竖线。
- 焦点：侧栏收起时，壳体内部焦点返回 `#workbench-sidebar-toggle`。

背景与空间。

- 材料：右侧侧栏、中间消息流和项目列表共用 `--workbench-frame-surface`，三个区域呈现同一工作台底色。
- 分隔：消息主列与右侧栏之间保留2px常驻分割线；项目模式只在内容行内显示，普通 `I` 模式将视觉线向上延伸到标题区，悬停、聚焦和待收起状态保持同一视觉。
- 位置：右侧壳体位于工作台内框内容行，从标题栏下方延伸至内框底边。
- 默认宽度：360px。
- 最小宽度：280px。
- 最大宽度：工作台可用宽度减去消息主列最小宽度360px。
- 拖拽：分割条热区8px；指针拖拽按动画帧更新，键盘使用ArrowLeft和ArrowRight，Shift组合步进64px。
- 拖拽边界：可交互热区位于内容行，标题栏区域不绘制分割线。
- 收起：拖拽宽度达到最小宽度减48px时进入待收起态，松开后关闭；Esc在拖拽过程中恢复起始宽度。
- 双击：双击分割条恢复360px默认宽度。
- 开合：宽度过渡180ms，内容淡入180ms、淡出90ms；减少动态效果偏好使用即时切换。

范围切换与状态。

- 项目默认入口：Project 列表为空时，右侧入口页提供添加项目引导；项目读取和默认激活期间提供加载或重试状态。
- 范围跟随：项目激活成功后，左侧项目选中态、中间历史和右侧侧栏同步更新到目标 `projectId`。
- 侧栏跟随：侧栏展开期间发生项目切换时，右侧回到目标范围的入口页；侧栏收起期间发生切换时保持收起。
- 目录实例：每个项目拥有独立 `ProjectDirectory`，保存目录页、展开节点、筛选和选中路径。
- 普通资源：普通范围根据当前前端状态合并草稿附件、已加载输入附件和已加载输出文件。
- Canvas：Canvas 组件按当前 `projectId` 加载和保存文档；侧栏收起时编辑器进入保留状态，连续保留10分钟后在允许条件下释放。
- 请求隔离：目录、附件和 Canvas 请求分别绑定项目身份与请求代次，当前范围采用最新成功结果。

宿主接口。

- 项目目录：`listProjectDirectory({ projectId, relativePath, cursor? })` 由 Main 返回一页只读目录元数据。
- 文件夹定位：`performProjectAction({ projectId, action: "reveal" })` 在系统文件管理器中打开已登记项目根目录。
- 资源目录：`openAttachmentsDirectory()` 在系统文件管理器中打开 AttachmentStore 管理的存储目录，由 Main 创建并解析固定位置。
- 上传原件：`openAttachment(attachmentId)` 打开 Main 保存的附件原件。
- 产物原件：`openOutputFile(runId, fileId)` 在现有产物路径校验后打开生成文件。
- 产物预览：`previewOutputFile(runId, fileId)` 返回文本、图片或明确的预览状态。
- Canvas 文档：`loadCanvasDocument(projectId)` 与 `saveCanvasDocument(...)` 由 Canvas 保存协调器调用。
