右侧工作侧栏。

- 范围：右侧只有一个侧栏壳体。输出文件面板和 Canvas 面板共享壳体宽度、开合动画、拖拽条与焦点隔离；Canvas 的具体规则见[Canvas](../canvas.mdx)。
- 位置：工作台内框右侧的内容行，与消息主列并排，背景、边界和内容共同使用标题行下方的剩余高度。
- 材料：次级表面颜色，左侧使用工作台分隔颜色，背景与边界从内框内容行顶边延伸至底边；关闭时壳体边界随宽度收起。
- 布局：与消息主列共享内框内容行的布局空间，采用并列分栏结构；应用操作按钮位于内框标题行，侧栏内容从标题行下方开始。
- 默认状态：关闭，开合状态保存在本次窗口生命周期。
- 尺寸：默认宽度360px，最小宽度280px；工作区可用宽度使用内框消息主列与右侧栏的实际宽度之和，覆盖外层留白、边框和项目列表后的剩余空间，侧栏的有效最大宽度由该可用宽度减去消息主列最小宽度360px计算。
- 宽度保持：拖拽结束后的用户偏好宽度和双击恢复的宽度写入本机偏好，当前窗口显示宽度按实时窗口约束计算；窗口缩小时暂时压缩有效宽度，窗口恢复后重新使用用户偏好宽度；拖拽过程中的临时宽度保存在当前交互状态。
- 主列约束：侧边栏展开时消息主列保留至少360px；工作区可用宽度小于侧边栏最小宽度与主列最小宽度之和时，侧边栏进入关闭状态，主列继续保留可用宽度。
- 开合动画：宽度过渡180ms；打开过程中内容180ms淡入，关闭过程中内容90ms淡出；宽度过渡结束后才切换到完全打开或关闭状态。
- 减少动画：系统开启减少动画时直接切换开合状态。
- 关闭状态：区域退出焦点顺序，并设置 aria hidden。
- Canvas 生命周期：应用启动后预热 Canvas 编辑器模块和当前项目文档；Canvas 首次打开后由侧栏宿主保持挂载。关闭侧栏时保留 Canvas 挂载，并切换为隐藏和交互禁用状态。Canvas 连续关闭 10 分钟后才释放编辑器实例、图片解码缓存和撤销状态，重新打开前会取消释放计时器。

输出文件按钮。

- 位置：内框主标题栏右端操作组中的输出文件按钮，排列在该组第一位。
- 交互：当前显示输出文件面板时触发后关闭侧栏；当前显示 Canvas 或侧栏关闭时触发后切换到输出文件面板。关闭后输出文件继续保留。
- 图标：侧边栏展开时使用现有 `sidebar` 图标；侧边栏收起时使用 `sidebar-collapsed` 图标，两个图标使用18×18px面板外框和 `rx=4` 圆角，并以靠右、上下内缩且圆角端点的竖线表示收起状态。
- 状态文字：打开状态使用隐藏输出文件，收起状态使用显示输出文件。
- 说明：侧栏开合由内框主标题栏的固定操作组承担，预览标题区保留名称与所属操作。

侧边栏拖拽条。

- 视觉令牌：默认1px线与悬停、聚焦、待收起状态的2px强调线分别读取 `--workbench-resizer-line` 和 `--workbench-resizer-emphasis`，与项目列表拖拽条使用同一套反馈。
- 位置：消息主列与侧边栏之间，贯穿侧边栏整列高度。
- 热区：宽度8px，视觉中心使用1px通用边界线。
- 指针：列宽调整形态。
- 拖拽交互：按下后停用宽度动画，宽度通过帧节流更新，并限制在最小宽度与当前窗口计算出的有效最大宽度之间；拖拽事件更新布局宽度，文件读取和项目历史加载沿用各自的数据请求。
- 主列重排：侧边栏宽度变化后，消息内容列和 Composer 根据主列剩余宽度重新排版；已挂载消息块沿用 MessageStream 的 ResizeObserver、高度缓存和滚动锚点修正，宽度变化保持已加载数据与 blockId 稳定。
- 收起阈值：拖拽宽度小于或等于最小宽度减48px时，边界线变为2px强调色并处于待收起状态；此时松开拖拽，侧边栏进入关闭流程，持久偏好沿用拖拽前的已确认宽度。
- 取消：拖拽过程中按 Esc 恢复到拖拽开始前的宽度，持久偏好保持原值。
- 双击：恢复默认宽度360px并写入本机偏好。
- 键盘：聚焦后 Arrow Left 或 Arrow Right 按16px步进调整宽度，按住 Shift 时步进64px；宽度已经到达最小值时继续按 Arrow Right 触发侧边栏关闭；调整后的宽度写入本机偏好。
- 无障碍：提供 separator 语义，方向为纵向，暴露当前有效宽度、最小宽度和随窗口变化的有效最大宽度。
- 共享交互：`frontend/src/shared/sidebar/useResizableSidebar.ts` 统一提供右侧工作侧栏与[项目列表](../../project-navigation.mdx)的拖拽、键盘、阈值收起和宽度偏好行为，两侧按各自方向和局部可用宽度计算实际尺寸。

输出面板布局。

- 起点：输出文件列表从内框内容行顶边开始，列表与预览区纵向分配标题行下方的侧栏可用高度。
- 标题操作：文件名称、刷新和系统打开操作位于预览区自身的标题栏，应用级操作继续使用内框主标题栏。

输出文件范围。

- 展示范围限定为当前运行登记的产物。新任务发送时切换文件范围。
- 当前 Bash 在命令执行前后扫描工作目录，比较文件元数据并报告产物；忽略依赖、构建输出等目录以及符号链接，扫描按数量和深度上限报告捕获范围内的文件变化。
- Main 为本次运行中新建文件分配 `fileId`；后续修改同一文件更新原条目。运行前已有文件沿用原文件身份，输出列表继续维护本次运行登记的产物。
- 文件按更新时间倒序显示。注册表保存在 Main 内存中，最多保留12个有产物登记的运行；磁盘文件的保存期限由文件自身生命周期决定。

输出文件列表。

- 位置：输出侧栏在工作台内框内容行中的顶边。
- 尺寸：占侧边栏高度最大百分之三十四且最小108px，内容超出时列表内部滚动。
- 内边距：7px。
- 分隔：底部使用通用边界。
- 条目尺寸：最小高度42px，垂直内边距6px，水平内边距7px，圆角8px。
- 条目内容：16px文件或图片图标，文件名11px四百五十字重，可读路径9px低强调文字，操作状态9px（创建显示已创建，更新显示已更新）。
- 条目布局：图标列20px，文字占其余宽度，状态标签靠右，列间距7px。
- 文字省略：文件名和路径单行省略。
- 选中与悬停：使用悬停反馈颜色。
- 选择策略：默认选择第一个文件；当前选中文件仍存在时保持原选择。
- 空状态：24px文件图标加当前任务的文件产物为空，居中展示。
- 无障碍：列表语义 listbox，条目语义 option，并提供选中状态。

文件预览区。

- 位置：文件列表下方，占据侧边栏剩余高度。
- 材料：主要表面颜色，内容超出时内部滚动。
- 标题栏：固定在预览区顶部，高度44px，水平内边距10px，底部通用边界，使用半透明主要表面颜色。
- 标题内容：当前文件名11px四百五十字重，文件大小9px低强调文字。
- 文本预览：11px等宽文字和18px行高，12px内边距，保留换行并在窗口内自动换行，制表符宽度为2个字符。
- 截断提示：文本内容超过512KB时只显示前512KB，预览底部显示文件较大仅显示前512KB的提示。
- 图片预览：支持 PNG、JPEG、GIF、WebP，在可用区域内等比缩放；超过5MB显示大小限制错误。其他类型根据媒体类型进入文本预览或类型限制状态。
- 加载中：显示正在读取预览…
- 类型限制：显示28px文件图标和内嵌预览能力提示，下方说明来源类型。
- 失败：显示警告图标与错误说明，使用危险操作颜色。
- 空选择：未选中文件时显示选择文件以预览内容。
- 刷新：选择文件、运行或文件更新时间变化时重新请求预览；Renderer 以 `runId + fileId + updatedAt` 标识当前目标，以递增的请求代数区分同一目标的连续刷新。IPC 使用 `runId + fileId` 读取文件；只有当前目标的最新请求可以提交预览内容、加载状态和错误。切换目标立即隐藏旧预览，空文件列表清空状态，组件卸载使未完成请求失效。读取失败（包括 IPC 拒绝）进入当前文件的错误状态并结束加载。

刷新预览按钮。

- 位置：预览标题栏右侧。
- 尺寸：热区28乘28px，圆角7px。
- 材料：透明背景，低强调文字颜色。
- 图标：refresh 语义图标15px。
- 交互：触发后重新读取当前文件的预览内容。
- 无障碍：提供 Tooltip 和无障碍名称刷新预览。

在系统中打开按钮。

- 位置：刷新预览按钮右侧。
- 尺寸：热区28乘28px，圆角7px。
- 材料：透明背景，低强调文字颜色。
- 图标：external 语义图标15px。
- 交互：触发后在系统默认应用中打开当前文件。请求失败（包括 IPC 拒绝）时在预览区底部显示错误提示，使用10px文字和危险操作颜色，以警报语义呈现；打开结果按所属文件和运行更新错误提示，过期结果按原请求处理，重新刷新预览时清除先前打开操作的提示。
- 无障碍：提供 Tooltip 和无障碍名称在系统中打开。
