普通资源视图。

- 交互状态：普通 `I` 范围使用 `projectId = null`；入口页、草稿附件、已加载消息附件、已加载运行产物、资源预览和原始文件打开已经接入。
- 页面分工：左侧承担工作区导航和项目列表，中间展示普通消息与 Composer，右侧入口页将存储位置、画布和资源统一组织在资源区域中。
- 初始状态：右侧左上角依次纵向排列 `View All Outputs` 与 `Open Canvas` 两个紧凑胶囊按钮，资源列表接在按钮组下方。
- 存储位置：点击 `View All Outputs` 后通过 `openAttachmentsDirectory()` 在系统文件管理器中打开应用管理的附件存储目录；Main 按 AttachmentStore 的配置取得目录并在首次使用时创建目录。
- 画布选择：点击 `Open Canvas` 后，右侧展示普通范围 Canvas；左上角浮动圆角返回按钮回到侧栏入口页，焦点返回画布入口。
- 资源选择：点击资源行后，右侧展示该资源的预览表面；左上角浮动圆角返回按钮回到资源列表。

页面排列。

```text
侧栏入口：左侧工作区导航 | 中间普通对话 | 右侧：View All Outputs / Open Canvas / 资源列表
资源阅读：左侧工作区导航 | 中间普通对话 | 右侧：所选资源预览
```

资源列表。

- 入口按钮：`View All Outputs` 与 `Open Canvas` 共享 `--surface-secondary` 背景、30px最小高度、4px垂直内边距、12px水平内边距和胶囊圆角；组内间距8px，组起点距离侧栏顶边与左边各12px。
- 入口文字：两个按钮使用共享英文界面字体 `--font`、13px字号 `--font-size-meta`、20px行高与500字重；按钮宽度随文字内容确定，并受侧栏可用宽度约束。
- 入口图标：文件夹与 line-squiggle SVG 使用18px尺寸、2px描边、透明底和8px图文间距；两个图标及文字分别沿统一左轴对齐。
- 入口反馈：整颗按钮悬停时使用 `--hover`，键盘聚焦采用工作台共享焦点反馈。
- 来源：列表合并当前草稿中的待发送附件、已加载运行的输入附件和已加载运行的输出文件；历史页运行在消息流完成加载并更新前端状态后加入列表。
- 排序：待发送与已加载输入附件按 AttachmentState 中的稳定插入顺序展示，输出文件按更新时间从新到旧展示。
- 身份：上传资源使用 `attachmentId`，运行产物使用 `runId + fileId`；相同名称的不同来源分别保留。
- 行布局：每行使用类型图标、资源名称、大小与状态组成的双行内容，右端提供独立的原始文件打开按钮。
- 文件图标：图片使用 image 图标，视频使用 film 图标，其他附件和产物使用 book-open 图标；图标尺寸18px。
- 行尺寸：整行最小高度44px、水平内边距4px、圆角8px；主内容按钮随可用宽度伸缩，原始文件按钮为30×30px热区。
- 文字：名称使用界面正文颜色与单行省略，状态行使用次要文字颜色；完整名称通过 Tooltip 提供。
- 悬停：鼠标进入整行时整行背景切换为 `--hover`，主内容与原始文件操作共享同一反馈。
- 空状态：资源列表为空时保留两个入口按钮与其下方留白，Composer 提供文件导入操作。

资源预览。

- 表面：资源预览使用侧栏完整可用高度，背景与消息流共用 `--workbench-frame-surface`。
- 返回：预览左上角固定30×30px、8px圆角的半透明返回按钮；悬停使用 `--hover`，图标沿用侧栏返回语义。
- 上传附件：图片、视频和音频使用受控 `attachment://` 地址播放或展示；系统打开入口覆盖全部附件，内嵌媒体能力可用的附件同时提供直接预览。
- 运行产物：文本和图片沿用现有产物预览接口，预览栏提供刷新与系统打开操作。
- 原始文件：上传附件通过 `openAttachment(attachmentId)` 打开 Main 保存的不可变原件，运行产物通过 `openOutputFile(runId, fileId)` 执行现有路径校验后打开。
- 错误：读取或系统打开失败时在所属列表或预览表面显示错误说明，侧栏其他资源继续可用。

背景与层级。

- 材料：普通入口页、资源列表、资源预览和 Canvas 共用工作台内框表面，侧栏与中间消息流保持同一底色。
- 入口页：两个胶囊按钮位于同一资源区域左上角，资源行沿侧栏宽度展开。
- 内容页：资源预览位于侧栏内容行，完整高度由工作侧栏壳体提供，滚动由预览区域自行管理。

范围与状态。

- 范围切换：项目切换成功后，已展开侧栏回到目标范围的入口页；普通资源状态保存在普通范围对应的组件状态中。
- 草稿附件：Composer 发布当前范围待发送附件，资源列表标记为 `Pending attachment`。
- 已发送附件：运行确认后，输入附件进入对应 run，资源列表标记为 `Uploaded`。
- 存储归属：上传原件保存在 Main 管理的 `attachments` 目录；运行产物保存在运行实际写入的工作路径，通过各行原始文件操作访问。
- 消息定位：从消息入口打开资源目标时复用同一附件或产物身份；当前阶段通过右侧预览承接内容。

实现边界。

- 本页交付普通范围入口、资源列表、整行悬停、原始文件打开和基础媒体预览。
- 文档正文、源码与 Markdown 的统一只读查看器由后续内容展示专题接入。
- 修改对比继续使用独立的目标身份，后续比较专题在同一侧栏中接入。
