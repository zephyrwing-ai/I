设置入口。

- 位置：左侧项目导航轨道底部，位于 `I` 与 `Project` 入口下方。
- 尺寸：热区横向填满导航轨道内容区，当前宽48px，左右分别距窗口左边和 `workbench-frame` 左边8px；圆角沿用现有控件几何。
- 材料：透明背景，次要文字颜色；悬停和激活状态使用悬停反馈颜色和主要文字颜色。
- 图标：入口以22px的 settings 齿轮图标单独呈现，Tooltip 与 `aria-label` 均保留 `Settings` 名称。
- 交互：触发后进入 Settings 页面，同步更新 `aria-expanded`。
- 焦点：Settings 页面打开后焦点进入 Back；页面返回后焦点回到设置入口。

Settings 页面。

- 位置：页面完整接管应用窗口，左侧显示设置导航，右侧显示当前模块。
- 布局：顶部独立窗口拖拽带与下方页面主体纵向排列，页面主体由左侧 Settings 导航区与右侧内容区组成。
- 导航：左侧按 Back、General、Providers、Usage、TTS 排列；模块按钮切换右侧对应内容，当前模块使用激活背景、主要文字颜色和 `aria-current="page"`。
- 展示隔离：Settings 打开时，原 `I / Project / Settings` 项目导航、`workbench-frame` 及工作台搜索与项目菜单等浮层进入隐藏状态；隐藏区域同步退出指针命中、键盘焦点顺序、辅助技术访问和原生拖拽热区。
- 状态保留：项目导航与工作台组件继续挂载，当前项目、已加载历史、消息滚动位置、Composer 草稿和 Canvas 场景沿用当前实例。
- 返回：Back 关闭 Settings 页面，恢复工作台展示与交互；工作台恢复后，下一动画帧将焦点返回左下 Settings 入口。
- 返回入口样式：Back 与模块按钮共用导航按钮基础样式，宽度填满左侧导航内容区，高度36px；Back 圆角16px、模块按钮圆角8px，字号读取 `--font-size-body`（14px），悬停使用 `--nav-hover`，当前模块使用更重的 `--nav-selected` 背景。
- 导航间距：Back 到 General、General 到 Providers 以及其余相邻模块的间距统一为4px，外层导航容器与模块列表共享同一条 `gap` 规则。
- 拖拽：左侧顶部拖拽带高度复用 `--topbar-height`（52px），为原生窗口控制按钮预留位置；右侧顶部拖拽带使用四份 `--workbench-frame-gap`（32px），同时形成模块内容的顶部留白。两处拖拽带使用 `-webkit-app-region: drag`，Back、模块按钮与右侧内容位于各自拖拽带下方的 `-webkit-app-region: no-drag` 内容区。
- 字体：沿用工作台统一字体、字号和字重 token。
- 色彩：沿用工作台表面、边界、文字和悬停 token。
- 几何：设置导航宽度复用 `--projects-panel-width`，页面间距、控件圆角与按钮尺寸沿用现有几何 token 和共享样式；全部设计值复用[设计令牌](../../tokens.mdx)。
- 内容对齐：页面标题和列表共用左侧对齐线，左右距内框内边缘40px，读取五份 `--workbench-frame-gap`；标题顶部距内框上内边缘32px，读取四份 `--workbench-frame-gap`。内容横向填满内框可用区域，Appearance、Language 每行跟随列表宽度，行高48px。
- General：显示 General 页面标题以及 Appearance、Language 两行，两行右侧分别复用同一共享 Select 选择控件。
- General 列表：背景沿用 `var(--input)`，圆角8px，外边框宽度0；每行高度48px，相邻行保留1px `var(--border)` 分隔线。
- General 归属：`frontend/src/workbench/settings/general/GeneralSettings.tsx` 承载模块内容与选择控件，`frontend/src/workbench/settings/general/GeneralSettings.css` 维护模块样式。
- 选择控件归属：`frontend/src/shared/ui/Select.tsx` 与 `frontend/src/shared/ui/Select.css` 统一承载模型、Appearance、Language 三处选择器的结构、基础样式、展开状态与键盘交互；各模块配置菜单方向、对齐和尺寸，浮层复用现有 Radix Popover。
- 选择触发器：最小高度32px，边框宽度0，默认背景透明；悬停与展开时使用 `var(--hover)` 背景和 `var(--text)` 文字。圆角读取 `--workbench-frame-radius`（16px），呈胶囊状；正文使用14px字号、22px行高、400字重，箭头复用共享 `chevron-right` 图标，收起时向右、展开时顺时针旋转90度向下，方向规则由共享 CSS 统一定义；键盘聚焦沿用统一焦点环。
- 选择菜单：通过 Portal 挂载到 `document.body`，使用 `align="end"`、`side="bottom"` 与 `sideOffset={8}`；菜单右边缘与触发器右边缘对齐，顶边始终位于触发器底边下方8px。表面使用 `var(--surface)`，边框宽度0，圆角读取 `--workbench-frame-radius`（16px），阴影沿用现有浮层层级。
- 选择条目：文字使用14px字号、22px行高、400字重；选中项文字和共享16px `check` 图标统一使用 `var(--text)`。
- 选择交互：ArrowUp、ArrowDown 移动活动选项，Home、End 移至首项或末项；Enter、Space 确认选择，Escape 或点击外部关闭菜单，Tab 关闭菜单并将焦点移至下一个控件。
- 点击范围：右侧选择按钮的文字、箭头和内边距共同组成鼠标触发热区；左侧名称作为普通说明文字，通过 `aria-labelledby` 提供控件名称，菜单展开由右侧按钮点击或键盘操作触发。
- Appearance：提供 System、Light、Dark 三项；System 随系统明暗偏好变化，Light 与 Dark 固定使用对应主题。解析后的主题通过根节点 `data-theme` 切换现有颜色 token，工作台与 Settings 共用主题状态，Canvas 编辑器接收同一主题值。
- Language：提供 English、简体中文两项；`frontend/src/shared/i18n/index.ts` 提供统一翻译与 `useI18n` 入口，`frontend/src/shared/i18n/locales/zh-CN.ts` 集中维护中文文案；设置导航、提供商表单、工作台导航、搜索、输入框和输出文件控件共用这一文案来源，Canvas 编辑器接收对应语言代码；品牌名称、用户消息、模型正文、项目名称和模型名称保留原文。
- 界面偏好：`frontend/src/shared/preferences/uiPreferences.tsx` 的 `UiPreferencesProvider` 在应用根部统一维护主题和语言，General 与工作台通过 `useUiPreferences` 读取和更新同一状态。Main 的 `UiPreferencesStore` 负责 `userData/ui-preferences.json`，通过 Preload 与 IPC 提供读取和更新；文件版本为1，包含 `appearance` 和 `language` 字段。
- 首次启动：应用建立系统用户数据目录，首次读取偏好时创建权限为0600的配置文件，默认外观为 System、语言为 English；已有文件优先恢复保存值。开发版与打包版在同一 `userData` 下共用该文件。
- 偏好迁移：Renderer 首次读取时提交当前来源可读取的旧 `workbench.uiPreferences` 值，Main 在配置文件首次创建时采用这些值，成功读取后清理该来源的旧记录。
- 偏好更新：Main 校验字段并顺序合并修改，通过临时文件与原子重命名发布完整配置；Renderer 在写入确认后更新界面，读取和保存失败时由 General 显示错误。主题切换保持工作台组件实例、输入草稿和运行状态。
- Providers：显示 Providers 页面标题，承载提供商列表、添加、模型发现、模型刷新、编辑保存和删除；列表与编辑视图在右侧模块区域内切换。
- Usage：显示 Usage 页面标题和内容区域。
- TTS：显示 TTS 页面标题和内容区域。
- 持久化：多个提供商按独立 providerProfileId 保存到本地 `provider-profiles.json`；每个记录包含名称、Base URL、`safeStorage` 加密的 API Key 和模型目录。重启后，在系统解密能力可用时恢复目录与凭据，恢复由 Main 的持久化数据读取完成。
- 页面状态：`frontend/src/App.tsx` 管理 Settings 开合、当前模块和入口焦点引用，`frontend/src/workbench/settings/SettingsPage.tsx` 与 `frontend/src/workbench/settings/SettingsPage.css` 组织页面布局、导航与模块挂载；页面切换沿用当前工作台状态与组件实例。
- 提供商链路：`frontend/src/workbench/settings/providers/` 归属 `ConfigPanel.tsx`、`ProviderEditor.tsx` 和 `providerCatalog.ts`，通过现有 Preload API 和 Main IPC 完成目录读取、模型发现、刷新、保存与删除；目录由 `useProviderCatalog` 提供，设置页与 Composer 共用当前目录结果。

刷新提供商按钮。

- 位置：卡片操作区首位。
- 尺寸：热区30乘30px，圆角7px。
- 材料：透明背景，低强调文字颜色；悬停状态使用悬停表面颜色和主要文字颜色；刷新进行中或运行期间禁用，禁用透明度为百分之五十八。
- 交互：触发后启动模型刷新，按钮显示旋转中的 refresh 图标，刷新期间锁定该入口；刷新成功后切换为 check 图标，并在成功反馈结束后恢复为 refresh 图标。
- 刷新间隔：目录回读期间列表区显示正在读取提供商。
- 成功反馈：成功后刷新按钮切换为 check 图标，使用与复制成功相同的主要文字颜色；2.2秒后自动恢复为 refresh 图标，成功反馈由图标状态表达。
- 刷新结果：模型目录完全以本次远端返回结果为准；返回的模型全部进入可用目录，本次远端结果之外的模型直接移除；已有模型沿用 modelOptionId，Composer 当前选择按新目录重新校验。
- 失败提示：错误说明显示在卡片下方，使用危险颜色，以警报语义呈现。

语音模型设置。

- 入口：设置页导航新增 Voice 分类，位于 TTS 之后。
- 列表：内置六个 whisper.cpp Whisper 量化模型与自动发现的本地 GGML 模型组成统一卡片列表，列表不区分来源，不显示 Local 标签；本地模型无法推断的 WER 保持不显示。
- 自动发现：应用启动、打开 Voice 设置和窗口重新聚焦时自动执行搜索；macOS 先通过 Spotlight 按文件名搜索 ggml 与 whisper 的 `.bin` 文件，再用 Downloads、`~/Library/Application Support/whisper.cpp` 和 `~/.cache/whisper.cpp` 的目录扫描兜底；只读取 GGML 文件头并限制候选数量与目录深度。
- 去重：扫描到的文件与内置清单匹配时直接标记为 Installed，用户无需重复下载；其余 GGML 文件按文件名显示为普通模型卡片。
- 选中圆点：卡片左侧显示选择圆点，已安装模型显示空心圆，当前选中模型显示中间实心点，选中卡片使用浅色选择表面背景；再次点击当前实心圆会取消选择，语音输入回到未配置状态。
- 状态按钮：卡片右侧使用固定宽度按钮，未下载显示 Download，下载中只显示整数百分比，已安装显示 Installed；下载中再次点击取消本次下载。
- 指标行：名称下方一行显示大小、内存估算、Speed 五格圆点等级和 WER；模型格式显示在名称右侧标签。
- 推荐：Whisper large-v3-turbo 显示 Recommended。
- 默认选择：随包模型在列表中显示为 Installed 并保持空心圆，首次使用语音输入前由用户点击圆点显式选中。
- 下载：Main 从 Hugging Face 的 ggerganov/whisper.cpp 仓库流式下载 GGML 文件到应用数据目录 voice-models，下载中每200ms推送百分比事件，完成后按 X-Linked-Etag 校验 SHA-256 并原子改名，失败和取消路径删除部分文件。
- 状态持久化：已安装模型、扫描到的本地模型路径与当前选择写入 voice-models-state.json；加载时检查本地文件仍存在且大小一致，语音转写优先使用选中的模型，模型失效或未选中时回退随包 turbo 模型。
- 数据范围：模型文件保存在 userData 的 voice-models 目录，仅由语音转写读取。
