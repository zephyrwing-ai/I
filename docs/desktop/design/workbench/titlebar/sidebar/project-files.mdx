项目文件视图。

- 交互状态：项目入口页、项目目录枚举、目录展开、分页加载、筛选、文件选中、刷新和系统文件管理器打开已经接入。
- 页面分工：左侧项目列表负责项目切换，中间展示当前项目消息与 Composer，右侧展示当前 `projectId` 的项目文件树。
- 初始状态：项目范围的入口页纵向居中排列 `Open workspace files` 与 `Open canvas` 两张等宽卡片。
- 目录入口：点击 `Open workspace files` 后，右侧以完整高度展示当前项目目录树。
- 画布入口：点击 `Open canvas` 后，右侧展示同一 `projectId` 的 Canvas。
- 选择结果：文件行点击后更新选中路径并在底栏显示项目相对路径；原文件内容查看器按后续专题接入。

页面排列。

```text
侧栏入口：左侧项目列表 | 中间项目对话 | 右侧：Open workspace files / Open canvas
目录浏览：左侧项目列表 | 中间项目对话 | 右侧：浮动返回 / 筛选与操作 / 项目目录树 / 选中路径
```

目录工具栏。

- 布局：左上角使用30×30px浮动返回按钮；顶部控制区从返回按钮右侧开始，依次排列筛选输入、刷新按钮和系统打开按钮。
- 返回：浮动按钮使用 `chevron-right` 图标并旋转180度，8px圆角、半透明表面、12px背景模糊和轻阴影；悬停使用 `--hover`。
- 筛选：输入框高度30px、圆角8px，默认显示 `Filter files`；输入内容后按名称大小写无关地过滤已加载目录内容。
- 焦点：筛选输入聚焦时保持默认边框、背景和圆角，工具栏通过光标和文字输入提供焦点反馈。
- 刷新：刷新按钮使用 refresh 图标；点击后清空当前项目的目录页缓存并重新读取项目根目录。
- 系统打开：刷新按钮右侧使用 external 图标；点击后通过 `performProjectAction({ action: "reveal" })` 在系统文件管理器中打开当前项目根目录。
- 错误：系统打开失败时在工具栏下方展示错误说明，目录继续提供浏览和重试。

目录行。

- 目录：一行展示展开箭头、文件夹图标和名称，点击箭头或整行切换子级展开。
- 文件：一行展示 book-open 图标与名称，点击后更新选中路径。
- 符号链接：一行展示 external 图标与名称，Main 将它作为只读展示项返回。
- 尺寸：目录和文件行最小高度30px，水平内边距8px，圆角8px；目录层级每级增加16px缩进。
- 文字：名称使用次要文字颜色并单行省略，完整相对路径通过 Tooltip 提供。
- 悬停：鼠标进入整行时整行背景切换为 `--hover`，文字切换为主要文字颜色。
- 选中：当前文件使用 `--selection` 背景与主要文字颜色，并在底栏显示项目相对路径。
- 键盘：目录使用 tree 与 treeitem 语义；ArrowUp、ArrowDown 移动焦点，Home、End 跳到首尾，ArrowRight 展开目录，ArrowLeft 收起目录或返回父级。

目录加载机制。

- 缓存身份：`WorkbenchSidebar` 为每个项目维护独立的 `ProjectDirectory` 实例；目录页、展开节点、选中路径、筛选文字和请求代次归属于该实例。
- 初始读取：用户第一次进入 `Open workspace files` 时读取项目根目录；`ProjectFileTree` 在 `active` 状态下调用 `load("")`。
- 懒加载：用户展开一个子目录时，前端检查该路径对应的目录页；目录页首次出现时调用 `listProjectDirectory`，后续展开复用缓存。
- 单层返回：每次请求返回一个目录层级的元数据，目录按目录优先、名称稳定排序。
- 分页：单页最多200项；返回 `nextCursor` 时显示 `Load more files`，点击后携带当前游标追加下一页。
- 游标绑定：游标包含目录版本、最后一个 `name + kind`；Main 校验项目、相对路径和目录版本，目录发生变化时返回 `stale_cursor`。
- 请求状态：每个目录独立维护 loading、error、entries 与 nextCursor；一个目录失败时其他目录继续保留。
- 文件变化：Main 在目录读取前后比较项目根、目录设备号、inode、mtime 和 ctime；读取期间发生变化时要求客户端从第一页重试。
- 筛选范围：筛选递归遍历当前已经加载的展开目录页，并隐藏名称不匹配的条目；展开目录后新增的页面继续参与同一筛选。

刷新职责。

- 刷新原因：文件树按目录缓存页面，外部应用新增、删除、移动或重命名文件后，现有页面保留缓存内容。
- 刷新动作：刷新清空当前项目的目录页缓存、取消当前请求代次并立即重新读取根目录。
- 状态恢复：刷新保留当前筛选文字、展开节点和选中路径；根目录读取完成后，`ProjectFileTree` 重新读取仍处于展开状态的目录路径。
- 自动加载：首次打开、目录展开和分页继续由文件树自动触发；刷新专门承接应用外部发生的文件系统变化。

Main 文件服务。

- 接口：Renderer 通过 `listProjectDirectory({ projectId, relativePath, cursor? })` 请求目录页。
- 项目校验：Main 每次通过 `ProjectRegistry.getDescriptor(projectId)` 取得注册项目的规范根路径，并使用请求中的 `projectId` 作为缓存与返回身份。
- 路径校验：相对路径使用 `/` 分隔，拒绝绝对路径、反斜杠、空段、`.`、`..` 和 NUL；解析后的真实路径必须位于项目根目录内。
- 根目录校验：项目根必须是当前规范路径且保持目录身份，根路径被替换为符号链接时返回 `project_changed`。
- 符号链接：符号链接作为 `kind: "symlink"` 元数据展示，Main 将它标记为只读条目。
- 页面内容：返回项包含 `name`、`relativePath` 与 `kind`；当前阶段返回目录元数据，文件正文由后续内容读取专题提供。
- 边界：目录服务只读、按项目身份访问，并与 Runner 的模型上下文扫描、项目激活和 Canvas 文档服务保持独立。

背景与范围。

- 材料：项目入口页、目录工具栏、文件树和 Canvas 共用 `--workbench-frame-surface`，与中间消息流保持同一底色。
- 范围切换：项目切换成功后，已展开侧栏回到目标项目入口页；再次选择工作目录时恢复该项目的目录实例状态。
- 组件生命周期：`WorkbenchSidebar` 保持挂载并按 `projectId` 复用目录实例；应用卸载时统一释放各目录实例的监听器与请求代次。

实现边界。

- 本页交付目录浏览、分页、筛选、刷新、原始文件夹定位与稳定项目范围。
- 文件正文读取、源码展示和 Markdown 渲染由后续内容读取专题接入。
- 修改状态、差异比较和项目级变化通知由后续比较专题接入。
