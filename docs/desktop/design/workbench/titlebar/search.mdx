全局搜索按钮。

- 位置：标题栏操作区第三位，位于 Canvas 按钮右侧，是右上角操作区的末位入口。
- 尺寸：热区30乘30px，圆角16px。
- 材料：透明背景，次要文字颜色；悬停和激活状态使用悬停反馈颜色和主要文字颜色。
- 图标：search 语义图标18px。
- 交互：触发后打开或收起搜索浮层；打开时焦点移入搜索输入框。按钮使用 `aria-expanded` 表示开合状态，并以 `aria-controls` 关联搜索浮层。
- 快捷键：Command+F 或 Ctrl+F 打开搜索浮层。
- 关闭行为：Esc 关闭搜索浮层并清空查询、结果选择和主消息流高亮；再次点击搜索按钮或点击浮层之外的区域只收起浮层，保留查询、结果和已有高亮。
- 搜索范围：索引正文由用户消息与身份已确认、位于折叠外的模型回答组成；活跃组回答由 `runCompleted.finalTurnId` 确认，已应用 steer 结束的前组沿用已提交的任务回答。过程文字与工具输入、输出通过活动详情阅读，原始 reasoning 由数据层保存并参与 Provider 续轮。
- 搜索数据：Renderer 从 AgentState 生成完整 MessageBlock 序列，渲染与搜索复用同一 `answerTurnId` 和正文文本字段。已挂载与离屏的已加载回答共同参与匹配；最终身份确认前的流式正文位于活动详情，身份确认后以原 blockId 进入回答索引。历史恢复沿用相同的回答判定与定位规则。
- 本地历史：查询非空且历史仍有更早页面时，搜索通过统一历史加载器显式读取本地分页并把结果投影进 AgentState；`scrollTop` 专门负责显示已经生成的虚拟消息块。搜索历史加载规则见[历史投影](../history-projection.mdx)。
- 匹配方式：对消息块文本执行大小写无关的包含匹配；每个消息块汇总为一条结果，摘要围绕该块中首次命中位置截取。
- 定位：选中结果后以结果的 blockId 定位对应消息块。已挂载消息块直接滚动到目标位置；离屏消息块由 MessageStream 调整虚拟窗口位置，完成挂载后再滚动到目标位置。
- 高亮：搜索列表中的命中词使用主要文字颜色和六百字重，省略上下文使用次要文字颜色；主消息流定位完成后为对应消息块添加 `--hover` 背景。高亮状态按 blockId 保存，虚拟块重新挂载后继续生效。
- 处理位置：文本匹配、结果生成、选择和高亮在 Renderer 本地完成；Main 只负责读取当前项目或无项目历史页。

搜索浮层。

- 位置：相对于软件视口居中，无论窗口全屏或缩小都保持水平居中；搜索条位于面板顶部，结果列表向下增长，面板周围保留12px视口内边距。
- 尺寸：宽度为560px与视口宽度减24px中的较小值；最大高度为视口高度减24px，结果超出后只滚动结果列表。
- 材料：面板使用 `--surface` 主要表面颜色，浅色 #FFFFFF、深色 #212121，水平内边距10px、18px圆角和1px通用边界；外部使用 `0 24px 58px` 搜索阴影与 `0 4px 14px` 轻量阴影。视口遮罩使用 `--backdrop` 与2px背景模糊。
- 语义：对话框角色，标签搜索全局内容。
- 输入框：高度36px，右侧内边距10px；搜索图标与透明输入框共享外层面板表面，图标列宽20px、列间距10px；结果列表顶部内边距8px，并沿用主要表面颜色的1px分隔边界。
- 输入聚焦：外层面板显示2px强调焦点环，并配合 `0 28px 70px` 搜索阴影与 `0 4px 16px` 轻量阴影；输入排版区域保持透明，面板尺寸保持稳定。
- 图标与文字：输入框左侧显示搜索语义图标18px，描边使用2px；输入区与结果行共用10px水平内边距、20px图标列和10px间距，搜索图标与中性圆环左边对齐，输入文字14px，Placeholder 为 `Search...`。
- 结果列表：查询非空时显示在输入框下方，最大高度400px并独立滚动；结果顺序与主消息流 MessageBlock 顺序一致，历史页插入后继续以 blockId 保持当前选择。
- 结果条目：一条结果对应一个含用户正文或模型回答正文的 MessageBlock，沿用该块的稳定 blockId 定位。条目最小高度36px、水平内边距10px、圆角8px，背景覆盖结果列表完整宽度；所有条目使用相同的尺寸、间距和文字起点。
- 中性标记：全部条目左侧统一使用18乘18px中性圆环标记和固定20px占位列，与正文间距10px。
- 条目文字：每条结果以该 MessageBlock 的单行文本作为完整内容。文字14px、行高22px，超出时单行裁切。
- 摘要：围绕命中词截取上下文；命中词必须完整保留并使用主要文字颜色和六百字重，前后未命中内容使用次要文字颜色，被裁去的前后内容分别以省略号表示。
- 状态：鼠标悬停的结果行使用覆盖完整宽度的 `--hover` 背景；加载更早历史、无匹配结果和读取失败分别使用单行状态条，输入区保持固定尺寸。读取失败保留已经得到的结果并提供重试入口。
- 选择：点击结果后保留浮层和查询，搜索列表保持透明行样式，同时主消息流跳转并高亮对应 MessageBlock。
- 无障碍：输入框提供搜索内容标签；结果列表使用 listbox 语义，条目使用 option 和选中状态，输入框通过 `aria-activedescendant` 关联当前结果。
- 打开行为：挂载后焦点直接落在输入框。
