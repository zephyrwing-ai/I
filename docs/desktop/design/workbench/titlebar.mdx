标题栏（右上角悬浮按钮组）。

- 位置：窗口右上角，固定悬浮于内容之上，不随侧边栏开合移动；侧边栏展开时按钮组悬浮于侧边栏之上。
- 尺寸：热区30乘30px，按钮之间间距4px；无背景容器。
- 位置坐标：纵向居中于顶部52px条带，按钮组右缘距离窗口右侧12px。
- 材料：不绘制背景、边界与阴影，直接悬浮于内容之上；按钮自身透明背景，悬停和激活状态使用悬停反馈颜色。
- 布局：消息主列与输出文件侧边栏均从窗口顶部开始、纵向贯穿全高；顶部52px为透明拖拽层，叠在内容之上，不占独立背景条，也不为主列保留起始高度。
- 拖拽：条带整体为窗口拖拽区域（`-webkit-app-region: drag`），按钮使用 no-drag 保持可点击；拖拽层覆盖内容顶部52px，该区域内不响应点击与文本选择，消息自绘滚动条位于拖拽层之上以保证顶部滑块可抓取。
- 结构：右侧操作入口排列，按钮之间间距4px。
- 语义：单一标题主工作台仅供屏幕阅读器使用（视口不可见）。

输出文件按钮。

- 位置：标题栏操作区第一位（最左侧）。
- 尺寸：热区30乘30px，圆角8px。
- 材料：透明背景，次要文字颜色；悬停和激活状态使用悬停反馈颜色和主要文字颜色。
- 图标：sidebar 语义图标18px。
- 交互：触发后切换侧边栏目标状态，更新 aria-expanded 并关联输出文件侧边栏控件。宽度过渡按侧边栏的宽度规则进行。
- 状态文字：打开状态使用隐藏输出文件，收起状态使用显示输出文件。
- 输出数量徽标：侧边栏收起且存在输出文件时在按钮右上角显示，计数超过9时显示9+。徽标为最小宽度15px，高度15px，水平内边距3px，8px圆角，使用主要强调颜色背景和白色文字，9px文字六百字重。
- 处理位置：按钮只切换侧边栏状态，运行请求由 Composer 发送。
- 侧边栏宽度：稳定宽度在本地存储中持久化，恢复时应用当前窗口宽度约束。

全局搜索按钮。

- 位置：输出文件按钮右侧（第二位）。
- 尺寸：热区30乘30px，圆角16px。
- 材料：透明背景，次要文字颜色；悬停和激活状态使用悬停反馈颜色和主要文字颜色。
- 图标：search 语义图标18px。
- 交互：触发后打开或收起搜索浮层，打开时焦点移入搜索输入框；按钮使用 `aria-expanded` 表示开合状态，并以 `aria-controls` 关联搜索浮层。
- 快捷键：全局面板快捷键使用 Command+F 或 Ctrl+F 打开搜索浮层。
- 关闭行为：Esc 关闭搜索浮层并清空查询、结果选择和主消息流高亮；再次点击搜索按钮或点击浮层之外的区域只收起浮层，保留查询、结果和已有高亮。
- 搜索范围：搜索结果由用户消息 MessageBlock 和最终模型消息 MessageBlock 组成。
- 搜索数据：Renderer 从 AgentState 生成完整的 MessageBlock 序列，消息块携带的原始文本字段构成唯一搜索数据源；已挂载和离屏的已加载消息块共同参与匹配。
- 本地历史：查询非空且历史仍有更早页面时，搜索通过统一历史加载器显式读取本地分页并把结果投影进 AgentState；`scrollTop` 专门负责显示已经生成的虚拟消息块。搜索历史加载规则见[历史投影](./history-projection.mdx)。
- 匹配方式：对消息块文本执行大小写无关的包含匹配；每个消息块汇总为一条结果，摘要围绕该块中首次命中位置截取。
- 定位：选中结果后以结果的 blockId 定位对应消息块。已挂载消息块直接滚动到目标位置；离屏消息块由 MessageStream 调整虚拟窗口位置，完成挂载后再滚动到目标位置。
- 高亮：搜索列表中的命中词使用主要文字颜色和六百字重，省略上下文使用次要文字颜色；主消息流定位完成后为对应消息块添加 `--hover` 背景。高亮状态按 blockId 保存，虚拟块重新挂载后继续生效。
- 处理位置：文本匹配、结果生成、选择和高亮在 Renderer 本地完成；Main 只负责读取当前会话的本地历史页。

设置按钮。

- 位置：标题栏操作区最右侧（第三位）。
- 尺寸：热区30乘30px，圆角8px。
- 材料：透明背景，次要文字颜色；悬停和激活状态使用悬停反馈颜色和主要文字颜色。
- 图标：settings 语义图标18px。
- 交互：触发后打开或关闭设置面板，同步更新 aria-expanded。
- 关联：打开时消息流，Composer 和输出文件侧边栏状态保持原样。
- 处理位置：打开时使用当前已加载的提供商目录。

搜索浮层。

- 位置：搜索面板的展开占位区域相对于软件视口居中，无论窗口全屏或缩小都保持水平居中；搜索条从打开时固定在该展开区域的顶部，结果列表向下增长，面板周围保留12px视口内边距。
- 尺寸：宽度为560px与视口宽度减24px中的较小值；最大高度为视口高度减24px，结果超出后只滚动结果列表。
- 材料：半透明玻璃面板，8px内边距，18px圆角，半透明渐变、背景模糊、柔和边界、外部阴影和顶部内高光；输入区与结果区组合为一个完整圆角面板。
- 语义：对话框角色，标签搜索全局内容。
- 输入框：高度36px，水平内边距10px；搜索图标和输入框直接属于外层玻璃面板，输入框直接使用面板表面，不单独绘制背景、边界或圆角；输入区与结果列表之间以8px间距和半透明分隔线衔接。
- 输入聚焦：聚焦状态由外层玻璃面板显示单一外部焦点环，输入排版区域保持透明，面板尺寸保持稳定。
- 图标与文字：输入框左侧显示搜索语义图标18px，描边使用2px；输入区与结果行共用10px水平内边距、20px图标列和10px间距，搜索图标与中性圆环左边对齐，输入文字与结果文字起点对齐；输入文字14px，Placeholder 为 `Searching...`。结果条目统一使用中性圆环标记。
- 结果列表：查询非空时显示在输入框下方，最大高度400px并独立滚动；结果顺序与主消息流 MessageBlock 顺序一致，历史页插入后继续以 blockId 保持当前选择。
- 结果条目：一条结果对应一个用户消息或最终模型消息 MessageBlock。条目最小高度36px、水平内边距10px、圆角8px，背景覆盖结果列表完整宽度；所有条目使用相同的尺寸、间距和文字起点。
- 中性标记：全部条目左侧统一使用18×18px中性圆环标记和固定20px占位列，与正文间距10px。
- 条目文本：每条结果以该 MessageBlock 的单行文本作为完整内容。文字14px、行高22px，超出时单行裁切。
- 摘要：围绕命中词截取上下文；命中词必须完整保留并使用主要文字颜色和六百字重，前后未命中内容使用次要文字颜色，被裁去的前后内容分别以省略号表示。
- 状态：鼠标悬停的结果行使用覆盖完整宽度的 `--hover` 背景；加载更早历史、无匹配结果和读取失败分别使用单行状态条，输入区保持固定尺寸。读取失败保留已经得到的结果并提供重试入口。
- 选择：点击结果后保留浮层和查询，搜索列表保持透明行样式，同时主消息流跳转并高亮对应 MessageBlock。
- 无障碍：输入框提供搜索内容标签；结果列表使用 listbox 语义，条目使用 option 和选中状态，输入框通过 `aria-activedescendant` 关联当前结果。
- 打开行为：挂载后焦点直接落在输入框。
