标题栏。

标题栏高度为40px，水平内边距为16px，使用主要表面颜色的半透明变体，底部使用通用边界。右侧操作入口之间的间距为4px。


输出文件按钮。

输出文件按钮位于标题栏右侧操作区的第一位。按钮热区为30乘30px，圆角为8px，默认使用透明背景和次要文字颜色，悬停和激活状态使用悬停表面颜色和主要文字颜色。

Renderer 在用户触发按钮后更新侧边栏目标状态和 aria expanded，并启动侧边栏宽度过渡。再次触发按钮时，Renderer 从当前宽度反向切换目标状态。

该按钮不发起 Agent 请求。稳定的侧边栏宽度由桌面偏好存储保存，恢复时重新应用当前窗口宽度约束。


全局搜索按钮。

全局搜索按钮位于输出文件按钮右侧。按钮使用与输出文件按钮相同的热区，圆角和状态颜色。

Renderer 在用户触发按钮后打开搜索浮层并将焦点移动到搜索输入框。用户点击浮层外部或按下 Esc 时关闭搜索浮层并将焦点返回搜索按钮。

搜索请求通过类型化 Preload 接口交给 Main。Main 查询本地历史索引并返回脱敏的匹配摘要，Renderer 不直接读取会话数据库。


设置按钮。

设置按钮位于标题栏操作区最右侧。按钮使用与其他标题栏按钮相同的热区，圆角和状态颜色。

Renderer 在用户触发按钮后打开设置面板。设置面板打开时保留消息流位置，Composer 状态和输出文件侧边栏状态。

Main 通过类型化 Preload 接口返回已经脱敏的提供商目录。返回数据包含提供商标识，提供商名称，API Base URL，凭据配置状态和已保存模型，不包含 API Key。


搜索浮层。

搜索浮层定位在标题栏下方，距离页面顶部44px，距离页面右侧48px。浮层宽度为380px，窄窗口下保留12px页面边距。浮层使用主要表面颜色，10px内边距，12px圆角，通用边界和轻量阴影。

搜索输入框高度为38px，水平内边距为10px，圆角为8px，使用输入表面颜色和通用边界。输入框左侧显示搜索语义图标，Placeholder 为搜索任务，命令或输出。

Renderer 根据输入内容更新搜索请求并展示匹配结果。清空输入时恢复默认结果状态。

Main 对查询进行标准化和长度限制，并只返回当前用户有权访问的历史内容。搜索索引不包含 API Key，认证头和 Provider 原始敏感负载。
