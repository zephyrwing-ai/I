标题栏。

- 位置：工作区顶部，覆盖全部宽度。
- 尺寸：高度40px，水平内边距16px。
- 材料：主要表面颜色的半透明变体，底部使用通用边界。
- 结构：右侧操作入口排列，按钮之间间距4px。
- 语义：单一标题主工作台供屏幕阅读器使用。

输出文件按钮。

- 位置：标题栏右侧操作区第一位。
- 尺寸：热区30乘30px，圆角8px。
- 材料：透明背景，次要文字颜色；悬停和激活状态使用悬停反馈颜色和主要文字颜色。
- 图标：sidebar 语义图标18px。
- 交互：触发后切换侧边栏目标状态，更新 aria-expanded 并关联输出文件侧边栏控件。宽度过渡按侧边栏的宽度规则进行。
- 状态文字：打开状态使用隐藏输出文件，收起状态使用显示输出文件。
- 输出数量徽标：侧边栏收起且存在输出文件时在按钮右上角显示，计数超过9时显示9+。徽标为最小宽度15px，高度15px，水平内边距3px，8px圆角，使用主要强调颜色背景和白色文字，9px文字六百字重。
- 处理位置：按钮只切换侧边栏状态，运行请求由 Composer 发送。
- 侧边栏宽度：稳定宽度在本地存储中持久化，恢复时应用当前窗口宽度约束。

全局搜索按钮。

- 位置：输出文件按钮右侧。
- 尺寸：热区30乘30px，圆角8px。
- 材料：透明背景，次要文字颜色；悬停和激活状态使用悬停反馈颜色和主要文字颜色。
- 图标：search 语义图标18px。
- 交互：触发后打开或关闭搜索浮层，打开时焦点移入搜索输入框。
- 快捷键：全局面板快捷键使用 Command+F 或 Ctrl+F 打开搜索浮层。
- 关闭行为：Esc 关闭搜索浮层并清空搜索内容；再次点击搜索按钮只收起浮层，保留查询及已有高亮。
- 搜索范围：当前页面 DOM 中标记为 `data-searchable` 的元素，包括用户消息、run 过程块和最终答案。折叠内容仍挂载，因此也参与匹配；不读取磁盘或未加载的历史记录。
- 匹配方式：大小写无关的包含匹配。
- 高亮：当前实现为命中元素整块添加背景（`--hover`），不是逐个命中词标注；嵌套的 run 与答案元素可能同时命中。
- 处理位置：匹配与高亮在 Renderer 本地完成。

- 尺寸：热区30乘30px，圆角8px。

搜索浮层。

- 位置：标题栏下方右侧，距离顶部44px，距离右侧48px。
- 尺寸：宽度为380px与窗口宽度减24px中的较小值。
- 材料：主要表面颜色，10px内边距，12px圆角，通用边界和轻量阴影。
- 语义：对话框角色，标签搜索全局内容。
- 输入框：高度38px，水平内边距10px，圆角8px，输入表面颜色和通用边界。
- 输入聚焦：聚焦状态显示主要焦点颜色边界和单一外部焦点环。
- 图标与文字：左侧显示搜索语义图标18px，与输入文字间距8px，输入文字14px，Placeholder 为搜索任务、命令或输出…。
- 无障碍：输入框提供搜索内容标签。
- 打开行为：挂载后焦点直接落在输入框。
