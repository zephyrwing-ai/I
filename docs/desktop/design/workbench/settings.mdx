设置面板。

- 位置：在窗口中央弹出，宽度为540px，窄窗口下左右各保留12px。
- 尺寸：宽度为540px与窗口宽度减24px中的较小值，最大高度为窗口高度减64px。
- 材料：主要表面颜色，通用边界，强阴影，14px圆角。
- 内边距：16px。
- 滚动：内容超出时只滚动设置面板内部。
- 标题：模型提供商，16px文字五百字重。
- 语义：对话框角色，标签关联模型提供商标题。
- 视图：打开时展示提供商列表视图；进入添加或编辑流程时，当前面板切换为提供商编辑视图，在同一面板内完成视图切换。
- 开合动画：开合过渡180ms，包含透明度位移与缩放；减少动态偏好下直接进行状态切换。
- 关闭行为：关闭后模型发现请求取消，编辑草稿和危险删除确认状态丢弃，焦点返回设置按钮。

关闭设置按钮。

- 位置：设置面板标题区右侧。
- 尺寸：热区30乘30px，圆角8px。
- 材料：透明背景，低强调文字颜色；悬停状态使用悬停表面颜色和主要文字颜色。
- 图标：close 语义图标16px。
- 交互：触发后关闭设置面板，按设置面板的关闭行为处理发现请求、草稿和焦点。
- 处理位置：本地完成，已保存的提供商数据保持原样。

提供商卡片。

- 位置：设置面板内部列表区，纵向排列。
- 尺寸：12px内边距，10px圆角，卡片之间保持10px间距。
- 材料：输入表面颜色，通用边界。
- 摘要内容：提供商名称，API Base URL，已导入模型数量；存在新增模型时追加新增数量。
- 名称：13px文字五百字重，超出部分显示省略号。
- 连接摘要：10px文字，低强调文字颜色。
- 操作按钮：热区30乘30px，圆角7px，按钮之间间距4px。
- 运行期间：暂时禁用。

提供商模型列表。

- 默认状态：收起。
- 展开动画：高度动画200ms，透明度动画150ms；展开指示旋转180ms。
- 列表结构：与卡片主体使用通用边界分隔，条目之间间距7px。
- 条目文字：模型标识12px，次要文字颜色，超出部分显示省略号。
- 状态标签：9px文字，2px6px内边距，9px圆角，与条目文字间距8px。
- 标签颜色：新增使用成功状态颜色和成功表面，不可用使用警告文字颜色和警告表面。
- 高度：随模型数量自适应。
- 记录范围：展开状态保留在面板本次打开期间，重新打开时从收起状态开始。

提供商展开按钮。

- 位置：占据卡片摘要区剩余宽度，展开指示位于摘要左侧，名称与连接摘要位于指示右侧。
- 材料：透明背景，无边界，文字继承卡片。
- 图标：chevron-right 语义图标14px，展开时旋转90度指向下方。
- 交互：触发后展开或收起当前卡片的模型列表，同步更新展开指示旋转和 aria-expanded。
- 关联：触发时清除当前危险删除确认状态。

刷新提供商按钮。

- 位置：卡片操作区首位。
- 尺寸：热区30乘30px，圆角7px。
- 材料：透明背景，低强调文字颜色；悬停状态使用悬停表面颜色和主要文字颜色；刷新进行中或运行期间禁用，禁用透明度为百分之五十八。
- 交互：触发后启动模型刷新，按钮显示旋转动画，刷新期间禁止重复触发。
- 刷新间隔：目录回读期间列表区显示正在读取提供商。
- 成功反馈：成功后卡片显示已重新拉取模型，2.2秒后自动消失。
- 刷新结果：远端新增模型列入待导入状态；远端消失的已保存模型列入不可用状态；已有模型保持原样，Composer 当前选择保持不变。
- 失败提示：错误说明显示在卡片下方，使用危险颜色，以警报语义呈现。

编辑提供商按钮。

- 位置：刷新提供商按钮右侧。
- 尺寸：热区30乘30px，圆角7px。
- 材料：透明背景，低强调文字颜色；悬停状态使用悬停表面颜色和主要文字颜色。
- 交互：触发后进入当前提供商的编辑视图，加载提供商名称，API Base URL，凭据配置状态和模型目录。
- 凭据显示：API Key 输入框保持空白，Placeholder 提示留空使用已保存凭据。
- 运行期间：暂时禁用。

删除提供商按钮。

- 位置：卡片操作区最右侧。
- 尺寸：热区30乘30px，圆角7px。
- 默认材料：透明背景，低强调文字颜色；悬停状态使用悬停表面颜色和主要文字颜色。
- 两阶段确认：第一次触发进入危险确认状态，使用危险操作表面和危险操作颜色；第二次触发提交删除。确认状态4秒后自动恢复默认状态，点击其他卡片操作时也恢复默认状态。
- 删除失败：错误说明显示在面板底部错误行，使用警告图标15px和危险颜色，以警报语义呈现。
- 删除成功：卡片从列表移除，目录同步更新；删除后 Composer 当前选择属于被删除提供商时，选择恢复为选择模型状态。
- 运行期间：暂时禁用。

添加提供商按钮。

- 位置：提供商列表下方，占据面板可用宽度。
- 尺寸：高度36px，圆角9px。
- 材料：主要文字颜色背景，白色文字。
- 交互：触发后建立独立的连接草稿和模型选择草稿，进入添加提供商编辑视图。
- 保存时机：保存动作由保存提供商按钮触发。
- 运行期间：暂时禁用。
