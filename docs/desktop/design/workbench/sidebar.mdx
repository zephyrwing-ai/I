输出文件侧边栏。

- 位置：窗口右侧，消息主列右侧；与主列一样从窗口顶部开始纵向贯穿全高，因此展开时整个右侧（含顶部区域）都是侧边栏，上方不存在标题条。
- 材料：次级表面颜色，左侧通用边界（关闭时隐藏），背景与边界从窗口顶部直达底部。
- 布局：与消息主列共享布局空间，不使用覆盖层，抽屉或浮动面板；顶部区域与右上角悬浮按钮组重叠，按钮组悬浮于侧边栏之上并保持可点击。
- 默认状态：关闭，开合状态不持久化。
- 尺寸：默认宽度360px，最小宽度280px；侧边栏没有产品定义的固定最大宽度，有效最大宽度由当前窗口宽度减去消息主列最小宽度360px计算，为消息主列保留可用空间。
- 宽度保持：拖拽结束后的用户偏好宽度和双击恢复的宽度写入本机偏好，当前窗口显示宽度按实时窗口约束计算；窗口缩小时暂时压缩有效宽度，窗口恢复后重新使用用户偏好宽度；拖拽过程中的临时宽度不写入。
- 主列约束：侧边栏展开时消息主列保留至少360px；窗口宽度小于侧边栏最小宽度与主列最小宽度之和时，侧边栏进入关闭状态，主列继续保留可用宽度。
- 开合动画：宽度过渡180ms；打开过程中内容180ms淡入，关闭过程中内容90ms淡出；宽度过渡结束后才切换到完全打开或关闭状态。
- 减少动画：系统开启减少动画时不做宽度过渡，直接切换开合状态。
- 关闭状态：区域标记为不可聚焦，并设置 aria hidden。

关闭入口。

- 位置：右上角悬浮按钮组中的输出文件按钮（最左侧第一位）。
- 交互：触发后关闭侧边栏，宽度过渡到零；不删除输出文件。
- 图标：侧边栏展开时使用现有 `sidebar` 图标；侧边栏收起时使用 `sidebar-collapsed` 图标，两个图标使用18×18px面板外框和 `rx=4` 圆角，并以靠右、上下内缩且圆角端点的竖线表示收起状态。
- 状态文字：打开状态使用隐藏输出文件，收起状态使用显示输出文件。
- 说明：侧边栏标题区不再设置独立关闭按钮，避免与固定悬浮在窗口右上角的按钮组重叠；关闭操作统一由悬浮按钮组承担。

侧边栏拖拽条。

- 位置：消息主列与侧边栏之间，贯穿侧边栏整列高度。
- 热区：宽度8px，视觉中心使用1px通用边界线。
- 指针：列宽调整形态。
- 拖拽交互：按下后停用宽度动画，宽度通过帧节流更新，并限制在最小宽度与当前窗口计算出的有效最大宽度之间；拖拽事件只更新布局宽度，不触发文件读取或会话数据加载。
- 主列重排：侧边栏宽度变化后，消息内容列和 Composer 根据主列剩余宽度重新排版；已挂载消息块沿用 MessageStream 的 ResizeObserver、高度缓存和滚动锚点修正，宽度变化保持已加载数据与 blockId 稳定。
- 收起阈值：拖拽宽度小于或等于最小宽度减48px时，边界线变为2px强调色并处于待收起状态；此时松开拖拽，侧边栏进入关闭流程，该临时宽度不保存。
- 取消：拖拽过程中按 Esc 恢复到拖拽开始前的宽度，不保存。
- 双击：恢复默认宽度360px并写入本机偏好。
- 键盘：聚焦后 Arrow Left 或 Arrow Right 按16px步进调整宽度，按住 Shift 时步进64px；宽度已经到达最小值时继续按 Arrow Right 触发侧边栏关闭；调整后的宽度写入本机偏好。
- 无障碍：提供 separator 语义，方向为纵向，暴露当前有效宽度、最小宽度和随窗口变化的有效最大宽度。

侧边栏顶部占位区。

- 位置：侧边栏顶部，即窗口顶部。
- 尺寸：高度50px，为右上角悬浮按钮组和窗口顶部操作区域保留空间。
- 内容：纯空间占位，输出文件列表从分隔线下方开始。

输出文件范围。

- 只展示当前运行登记的产物，不是项目文件浏览器，也不汇总历史运行。新任务发送时切换文件范围。
- 当前 Bash 在命令执行前后扫描工作目录，比较文件元数据并报告产物；忽略依赖、构建输出等目录以及符号链接，扫描存在数量和深度上限，不保证列出所有文件变化。
- Main 为本次运行中新建文件分配 `fileId`；后续修改同一文件更新原条目。修改运行前已存在、且本次运行未登记过的文件不会加入输出列表。
- 文件按更新时间倒序显示。注册表保存在 Main 内存中，最多保留12个有产物登记的运行；不等同于磁盘文件的保存期限。

输出文件列表。

- 位置：顶部占位区下方。
- 尺寸：占侧边栏高度最大百分之三十四且最小108px，内容超出时列表内部滚动。
- 内边距：7px。
- 分隔：底部使用通用边界。
- 条目尺寸：最小高度42px，垂直内边距6px，水平内边距7px，圆角8px。
- 条目内容：16px文件或图片图标，文件名11px四百五十字重，可读路径9px低强调文字，操作状态9px（创建显示已创建，更新显示已更新）。
- 条目布局：图标列20px，文字占其余宽度，状态标签靠右，列间距7px。
- 文字省略：文件名和路径单行省略。
- 选中与悬停：使用悬停反馈颜色。
- 选择策略：默认选择第一个文件；当前选中文件仍存在时，新文件不抢占选择。
- 空状态：24px文件图标加当前任务尚未生成文件，居中展示。
- 无障碍：列表语义 listbox，条目语义 option，并提供选中状态。

文件预览区。

- 位置：文件列表下方，占据侧边栏剩余高度。
- 材料：主要表面颜色，内容超出时内部滚动。
- 标题栏：固定在预览区顶部，高度44px，水平内边距10px，底部通用边界，使用半透明主要表面颜色。
- 标题内容：当前文件名11px四百五十字重，文件大小9px低强调文字。
- 文本预览：11px等宽文字和18px行高，12px内边距，保留换行并在窗口内自动换行，制表符宽度为2个字符。
- 截断提示：文本内容超过512KB时只显示前512KB，预览底部显示文件较大仅显示前512KB的提示。
- 图片预览：支持 PNG、JPEG、GIF、WebP，在可用区域内等比缩放；超过5MB显示大小限制错误。其他类型根据媒体类型进入文本或不支持状态。
- 加载中：显示正在读取预览…
- 不支持：显示28px文件图标加暂不支持内嵌预览，下方说明来源类型。
- 失败：显示警告图标与错误说明，使用危险操作颜色。
- 空选择：未选中文件时显示选择文件以预览内容。
- 刷新：选择文件变化或文件更新时间变化时重新请求预览。

刷新预览按钮。

- 位置：预览标题栏右侧。
- 尺寸：热区28乘28px，圆角7px。
- 材料：透明背景，低强调文字颜色。
- 图标：refresh 语义图标15px。
- 交互：触发后重新读取当前文件的预览内容。
- 无障碍：提供 Tooltip 和无障碍名称刷新预览。

在系统中打开按钮。

- 位置：刷新预览按钮右侧。
- 尺寸：热区28乘28px，圆角7px。
- 材料：透明背景，低强调文字颜色。
- 图标：external 语义图标15px。
- 交互：触发后在系统默认应用中打开当前文件。请求失败时在预览区底部显示错误提示，使用10px文字和危险操作颜色，以警报语义呈现。
- 无障碍：提供 Tooltip 和无障碍名称在系统中打开。
