消息流。

消息流区域。
- 区域内边距：上下各30px，桌面宽度下水平两侧各24px。
- 内容列最大宽度：760px，水平居中。
- 空状态：空白视图。

历史投影与虚拟渲染。

- MessageStream 接收统一的 AgentState，历史恢复和实时运行使用同一套 RunState、TurnState 和 ToolState。
- SessionEntry 到页面状态的转换由历史投影完成；MessageStream 不直接读取 SQLite，也不解析 SessionEntry。
- MessageStream 始终使用虚拟窗口：根据 scrollTop、viewportHeight 和已测量消息高度计算 visibleRange，并渲染可见消息与 overscan 消息。
- 虚拟窗口前后使用占位高度保持完整滚动范围；历史缓存可以包含多页消息，DOM 只挂载当前可见区域附近的消息。
- 历史消息从顶部追加时，Renderer 记录插入前的 scrollHeight 和 scrollTop，在 DOM 更新后按高度差修正 scrollTop，保持用户阅读位置。
- 首次历史加载完成后，消息流定位到最新消息；实时 AgentEvent 继续更新同一 AgentState，并由 MessageStream 的虚拟窗口显示当前运行内容。
- 工具折叠、reasoning 折叠、输出预览和展开状态属于页面投影状态；完整 reasoning、toolCalls 和 tool_result 由会话存储提供。
- 分页、hydrate 和实时事件合并以[历史投影](./history-projection.mdx)为准。

虚拟窗口数据模型。

- MessageStream 先把 AgentState 转换成有稳定身份的 MessageBlock 序列；用户消息、run 过程块和最终答案分别拥有稳定 blockId。
- blockId 由 runId、turnId 和块类型组成，虚拟窗口和高度缓存都不使用数组位置作为身份。
- 每个 MessageBlock 保存估算高度和已测量高度；首次布局使用估算值，ResizeObserver 返回真实高度后只更新受影响区间的累计高度。
- 可见范围通过 scrollTop、viewportHeight 和累计高度索引计算；overscan 在视口上下各保留一段内容，覆盖快速滚动和动态高度误差。
- DOM 结构固定为顶部 spacer、可见 MessageBlock 和底部 spacer，两个 spacer 共同表示未挂载内容的总高度。
- 当前流式 Assistant Message 保持在虚拟窗口中；增量改变高度时更新测量缓存，并在用户停留底部时保持吸底。

分页触发与滚动锚点。

- MessageStream 接近顶部阈值时调用 `onLoadOlder`，请求状态和 cursor 由历史 hook 管理。
- 旧页面插入前记录第一个可见 blockId 及其视口偏移；插入和测量完成后恢复同一 blockId 的偏移。
- loadingOlder 期间显示不改变布局高度的顶部加载状态，并禁止重复触发。
- hasMore=false 时顶部进入正常弹性边界；hasMore=true 时历史加载先于“已经到达完整历史开头”的语义。
- 历史请求失败保留当前列表和锚点，顶部状态提供重试，不清空已加载页面。

折叠与动态高度。

- run、turn 和工具折叠继续使用 Renderer 本地状态；历史 hydrate 后默认折叠。
- 展开 reasoning、工具输入或工具输出会改变 MessageBlock 高度，ResizeObserver 更新高度缓存并保持当前锚点。
- 长工具输出的600字符预览和320px内部滚动继续限制单个块的布局成本；复制操作使用完整结果。
- reasoning、toolCalls 和 tool_result 已由会话存储提供，虚拟渲染不改变其保存和恢复规则。

搜索边界。

- 虚拟渲染后，未挂载的已加载消息仍存在 AgentState，搜索不能再只遍历当前 DOM。
- 搜索使用历史投影中的可搜索文本建立 Renderer 本地匹配结果；选中离屏结果时，MessageStream 先滚动到对应 blockId，再对已挂载块应用高亮。
- 未加载的磁盘历史不参与当前页面搜索；需要全量历史搜索时使用独立的持久化检索能力。

滚动区域与覆盖。
- 覆盖关系：Composer 固定在消息主列底部，消息在其后方滚动，重叠区域由 Composer 表面覆盖。
- 底部占位：内容列末尾预留与 Composer 实际高度相等的占位，高度随输入与附件增减同步更新，保证滚动到底时最后一条消息完整停在 Composer 上缘。
- 滚动条与回弹：滚动条样式、跟手与回弹交互见[弹性回弹滚动](./elastic-scroll.mdx)。

折叠行（working for）。
- 状态词：运行中使用 Working for 加运行时间；完成后使用 Worked for 加运行时间。
- 运行的时长：本次运行的全部时间。
- 时间格式：不足10s保留一位小数；不足60s取整秒；60s以上转分钟（126s → 2m6s）；1小时以上转小时。
- 行本体：最小高度32px，下方内边距4px，行下方使用1px通用边界分隔线（`--border`，#1C1D221F）。
- 行文字：14px，行高20px，低强调文字颜色，字距0.02em。
- 扫光效果：行文字以渐变景光纹理呈现，沿水平方向匀速循环，周期4.2s。
- 折叠箭头：复用系统 Icon 的 chevron-right，15×15px，紧邻状态词右侧，与状态词间距8px。收起时指向右，展开后旋转90度指向下，变化时长180ms，使用先快后慢缓动。
- 展开动画：高度0fr到1fr，时长240ms；透明度0到1，时长200ms；入场位移自-2px回至0，时长240ms；使用先快后慢缓动。

折叠内容。
- 内容组成：思考块、过程文本、工具执行行；按回合顺序扁平直接堆叠。
- 思考块：模型内部推理（reasoning 通道，reasoningDelta 累加，来源为 reasoning_content 字段与正文夹带的 `<thinking>`/DSML 标记，由适配层剥离归入该通道）在每个有推理内容的回合顶部经 `MarkdownText` 展示（无标签，保留列表、标题、代码块等结构），随推理增量实时流式增长；正文只保留可见内容。
- 思考块样式：正文14px，行高24px，主要文字颜色，字距0.02em，最大宽度680px——字样与用户消息一致（无气泡背景）；按空行分段，段间8px。
- 间距：思考块与过程文本之间8px；过程文本段落之间8px；思考块、过程文本与回合折叠行之间均为6px（叠加行高半行距后视觉约17px）。
- 过程文本：14px，行高24px，次要文字颜色，最大宽度680px。
- 通道说明：过程文本是未作为答案展示的回合正文（assistant 通道）。Renderer 不根据文意猜测或生成 reasoning 通道；提供商适配层未输出独立推理时，只按收到的正文及工具事件归位。
- 段落间距：过程文本段落之间8px；相邻回合的过程文本按8px段间距继续堆叠。
- 结构呈现：思考块、过程文本和最终答案共用 `MarkdownText`，按 Markdown 结构解析；单次换行保留为 `<br>`，块间距由统一 `.markdown` 样式控制。

回合动作折叠。
- 层级：run 折叠行之下，每个回合的全部 agent 操作（工具调用，读文件，列目录等）组建一个回合级折叠；回合折叠内每个操作再分别折叠一次，构成 run 折叠到回合折叠到操作折叠的三级结构。
- 回合折叠行：语义图标加动作类型摘要加折叠箭头，单行。摘要按操作类型聚合组合，如 Loaded a tool, read files, ran commands；同类操作合并为一条短语，排列顺序按照执行顺序。
- 回合折叠行样式：与工具执行行同款——图标16×16px，描述 PingFang SC regular（400）、14px行高22px、次要文字颜色；单行显示，超长省略；折叠箭头15×15px，复用 chevron-right，紧邻动作摘要右侧，与摘要间距8px；收起时指向右，展开后旋转90度指向下；箭头默认隐藏，悬停该行时淡入显示（120ms），该行展开后保持显示。
- 悬停反馈：与工具执行行一致——悬停折叠行本体时描述字体加深为主要文字颜色并描边加粗（笔画增粗、字形度量不变），图标同步加深；行背景保持透明；反馈只作用于折叠行自身，悬停其内部工具行时标题不产生任何变化。
- 回合折叠内容：该回合的全部操作行，按调用顺序扁平堆叠，左侧与回合折叠行左缘对齐；首行与回合折叠行的纵向间距与工具行之间一致：相邻行盒间距为0，字形到字形距离同为26px。
- 折叠交互：回合折叠与 run 折叠独立展开收起；回合内各操作独立展开收起，互不影响。
- 展开动画：高度0fr到1fr，时长200ms；透明度0到1，时长180ms；使用先快后慢缓动。
- 默认状态：回合折叠收起；未调用工具的回合不生成回合折叠行。

工具执行行。
- 位置：位于回合动作折叠内，属于该回合的操作；回合折叠展开后按调用顺序呈现。
- 行结构：16×16px工具图标加动作描述加折叠箭头，单行。
- 动作描述：动词开头加实际操作内容。bash 为 Ran 加命令文本，read 为 Read 加文件路径，write/edit 为 Edited file，search 为 Searched 加查询文本；未知工具名显示工具名本身。
- 动作描述字体：PingFang SC regular（400），14px，行高22px，与回合折叠行描述一致，次要文字颜色；单行显示，超长省略。
- 行盒：高26px，无竖向内边距，行间无外边距——行距由行高半行距（4+4）与居中余量（2+2）自然形成，与回合折叠行同规格。
- 收起状态：显示工具图标与动作描述；折叠箭头默认隐藏，悬停该行时淡入显示（120ms），与回合折叠行箭头一致。
- 收起悬停反馈：字体加深为主要文字颜色并描边加粗（笔画增粗、字形度量不变），工具图标同步加深，折叠箭头淡入；行背景保持透明。
- 展开状态：静态外观，悬停仅字体加深与描边加粗；折叠箭头保持显示并指向下。
- 折叠箭头：复用系统 Icon 的 chevron-right，15×15px，紧邻动作描述右侧，与描述间距8px。收起时指向右，展开后旋转90度指向下，变化时长180ms，使用先快后慢缓动。
- 展开内容：输入参数和输出；等宽字体14px，行高20px，低强调文字颜色，输出卡片使用次级表面颜色填充和10px圆角。
- 对齐：与消息流左对齐。

悬停高亮（公共约定）。
- 语义：悬停表示该行可展开，以「颜色加深＋描边加粗＋箭头淡入」呈现，称为点亮；字形度量不变。
- 颜色：次要文字颜色 → 主要文字颜色。
- 字体：工具部分使用系统 PingFang SC regular（400）；悬停加粗为描边增粗笔画（合成加粗），字形度量不变，瞬时生效，不参与过渡。
- 强调机理：静止刻度较浅（regular 细笔画＋中灰），悬停跳至主要色近黑——明度步幅大，叠加描边加粗与箭头淡入构成「点亮」；静止态过深或步幅不足时，仅加深无法形成强调。
- 过渡：图标与文字同步150ms；箭头淡入120ms。
- 背景：始终透明，不出现背景色块。
- 适用范围：回合折叠行与工具执行行同等适用；反馈只作用于指针所悬停的行的本体。

工具列表块。

- 顶部标签：卡片上方显示工具类型标签，bash 使用 Shell；等宽14px，低强调文字颜色，与下方命令字号相同。
