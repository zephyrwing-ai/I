消息流。

消息流区域。
- 区域内边距：上下各30px，桌面宽度下水平两侧各24px。
- 内容列最大宽度：760px，水平居中。
- 空状态：空白视图。

滚动条。
- 滑块颜色：浅灰色（#B4B8BF），悬停加深（#9198A3）。
- 轨道宽度：12px（竖向滚动条的横向厚度）；滑块视觉宽度8px，滑块与窗口右缘保持2px空隙。滑块与窗口底部保持2px的空隙
- 滑块长度：按内容比例缩放（视口高 × 视口高 ÷ 内容总高），钳制最小48px、最大72px——内容极长时收至48px下限，内容很少时保持72px上限、不随内容减少而占满整条轨道；端头圆角8px。
- 玻璃质感：滑块为实心胶囊加玻璃高光模拟——主体使用垂直微渐变，顶部较亮（#BEC2C9）过渡到底部（#B4B8BF，45%位置），顶部叠加0.5px白色内高光（rgba(255,255,255,0.6)）模拟玻璃反光。
- 悬停状态：指针悬停滑块或拖拽期间，渐变加深（#9AA1AB 至 #9198A3），内高光减弱（rgba(255,255,255,0.35)）；颜色与滑块颜色变化在120ms内过渡。
- 显示行为：滑块一直显示；指针悬停轨道或滑块、拖拽期间、区域内键盘聚焦时保持显示；悬停滑块时颜色加深。
- 定位：消息流滚动容器占满消息主列宽度，滚动条位于窗口最右侧；760px内容列在容器内水平居中，与滚动条位置相互独立。
- 轨道与四角：透明背景，与页面表层颜色一致。
- 滚动范围：滚动容器占满消息主列整列高度并延伸至列底，滚动条轨道随容器贯穿至列底，与 Composer 区域重叠。
- 覆盖关系：Composer 覆盖在滚动容器底部并固定不动、不参与滚动；消息滚入其后方区域时被其遮挡。
- 底部占位：内容列末尾预留与 Composer 实际高度相等的占位，高度随输入与附件增减同步更新，保证滚动到底时最后一条消息完整停在 Composer 上缘。

模型消息（最终答案）。
- 最大宽度：680px。
- 文字：14px，行高24px，阅读黑色（`--text-reading`，#23242A），字距0.02em。

markdown 结构层间距（最终答案内容内）。

- 结构块（标题、列表、表格、代码块、引用）：上边距与下边距各12px，与正文段落拉开层级。
- 分隔线（`---`）：只留间距不留线——上边距与下边距各12px，无可见线条，仅以空隙分隔区块。
- 行内断行：单次换行以 `<br>` 呈现、行距24px，构成连续文本，不占用段落间距。

折叠行（working for）。
- 状态词：运行中使用 Working for 加运行时间；完成后使用 Worked for 加运行时间。
- 运行的时长：本次运行的全部时间。
- 时间格式：不足10s保留一位小数；不足60s取整秒；60s以上转分钟（126s → 2m6s）；1小时以上转小时。
- 行本体：最小高度32px，下方内边距4px，行下方使用1px通用边界分隔线（`--border`，#1C1D221F）。
- 行文字：14px，行高20px，低强调文字颜色，字距0.02em。
- 扫光效果：行文字以渐变景光纹理呈现，沿水平方向匀速循环，周期4.2s。
- 折叠箭头：复用系统 Icon 的 chevron-right，15×15px，紧邻状态词右侧，与状态词间距8px。收起时指向右，展开后旋转90度指向下，变化时长180ms，使用先快后慢缓动。
- 展开动画：高度0fr到1fr，时长240ms；透明度0到1，时长200ms；使用先快后慢缓动。
- 默认状态：折叠。

折叠内容。
- 内容组成：思考块、过程文本、工具执行行；按回合顺序扁平直接堆叠。
- 思考块：模型内部推理（reasoning 通道，reasoningDelta 累加，来源为 reasoning_content 字段与正文夹带的 `<thinking>`/DSML 标记，由适配层剥离归入该通道）在每个有推理内容的回合顶部以纯文本块展示（无标签），随推理增量实时流式增长；正文只保留可见内容。
- 思考块样式：正文14px，行高24px，主要文字颜色，字距0.02em，最大宽度680px——字样与用户消息一致（无气泡背景）；按空行分段，段间8px。
- 间距：思考块与下方内容8px；过程文本段落之间8px，文本和工具之间6px。
- 过程文本：14px，行高24px，次要文字颜色，最大宽度680px。
- 通道说明：过程文本是模型在回合间输出的可见正文（assistant 通道）。模型没有独立 reasoning 通道时，其推理以过程文本形式出现。
- 段落间距：过程文本段落之间8px；相邻回合的过程文本按8px段间距继续堆叠。
- 分段呈现：过程文本按空行分段，每个段落独立呈现，段间保持8px间距。

回合动作折叠。
- 层级：run 折叠行之下，每个回合的全部 agent 操作（工具调用，读文件，列目录等）组建一个回合级折叠；回合折叠内每个操作再分别折叠一次，构成 run 折叠到回合折叠到操作折叠的三级结构。
- 回合折叠行：语义图标加动作类型摘要加折叠箭头，单行。摘要按操作类型聚合组合，如 Loaded a tool, read files, ran commands；同类操作合并为一条短语，排列顺序按照执行顺序。
- 回合折叠行样式：与工具执行行同款——图标16×16px，描述 PingFang SC regular（400）、14px行高22px、次要文字颜色；单行显示，超长省略；折叠箭头15×15px，复用 chevron-right，紧邻动作摘要右侧，与摘要间距8px；收起时指向右，展开后旋转90度指向下；箭头默认隐藏，悬停该行时淡入显示（120ms），该行展开后保持显示。
- 悬停反馈：与工具执行行一致——悬停折叠行本体时描述字体加深为主要文字颜色并描边加粗（笔画增粗、字形度量不变），图标同步加深；行背景保持透明；反馈只作用于折叠行自身，悬停其内部工具行时标题不产生任何变化。
- 回合折叠内容：该回合的全部操作行，按调用顺序扁平堆叠，左侧与回合折叠行左缘对齐；首行与回合折叠行的纵向间距与工具行之间一致，均为8px——与文本-文本间距同宽。
- 折叠交互：回合折叠与 run 折叠独立展开收起；回合内各操作独立展开收起，互不影响。
- 默认状态：回合折叠收起；未调用工具的回合不生成回合折叠行。

工具执行行。
- 位置：位于回合动作折叠内，属于该回合的操作；回合折叠展开后按调用顺序呈现。
- 行结构：16×16px工具图标加动作描述加折叠箭头，单行。
- 动作描述：动词开头加实际操作内容。bash 为 Ran 加命令文本，read 为 Read 加文件路径，write/edit 为 Edited file，search 为 Searched 加查询文本；未知工具名显示工具名本身。
- 动作描述字体：PingFang SC regular（400），14px，行高22px，与回合折叠行描述一致，次要文字颜色；单行显示，超长省略。
- 收起状态：显示工具图标与动作描述；折叠箭头默认隐藏，悬停该行时淡入显示（120ms），与回合折叠行箭头一致。
- 收起悬停反馈：字体加深为主要文字颜色并描边加粗（笔画增粗、字形度量不变），工具图标同步加深，折叠箭头淡入；行背景保持透明。
- 展开状态：静态外观，悬停仅字体加深与描边加粗；折叠箭头保持显示并指向下。
- 折叠箭头：复用系统 Icon 的 chevron-right，15×15px，紧邻动作描述右侧，与描述间距8px。收起时指向右，展开后旋转90度指向下，变化时长180ms，使用先快后慢缓动。
- 展开内容：输入参数和输出；等宽字体14px，行高20px，低强调文字颜色，输出卡片使用次级表面颜色填充和10px圆角。
- 对齐：与消息流左对齐。

悬停高亮（公共约定）。
- 语义：悬停表示该行可展开，以「颜色加深＋描边加粗＋箭头淡入」呈现，称为点亮；字形度量不变。
- 颜色：次要文字颜色 → 主要文字颜色。
- 字体：工具部分使用系统 PingFang SC regular（400）；悬停加粗为描边增粗笔画（合成加粗），字形度量不变，瞬时生效，不参与过渡。
- 强调机理：静止刻度较浅（regular 细笔画＋中灰），悬停跳至主要色近黑——明度步幅大，叠加描边加粗与箭头淡入构成「点亮」；静止态过深或步幅不足时，仅加深无法形成强调。
- 过渡：图标与文字同步150ms；箭头淡入120ms。
- 背景：始终透明，不出现背景色块。
- 适用范围：回合折叠行与工具执行行同等适用；反馈只作用于指针所悬停的行的本体。

工具列表块。

输出查看器。
