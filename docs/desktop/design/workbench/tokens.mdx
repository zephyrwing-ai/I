设计令牌。

- 主题解析：Appearance 的 System、Light、Dark 选择统一解析为浅色或深色，通过根节点 `data-theme` 启用对应颜色令牌；System 持续读取系统明暗偏好，手动选择保持对应主题。
- 页面背景颜色：中性灰阶（浅色 #F8F8F8，深色 #171717），Canvas 与通用背景使用这一颜色；应用外壳使用独立外壳表面，工作台内框使用独立的抬升表面，右侧工作侧栏使用次级表面颜色并沿内框内容行伸展。
- 主要表面颜色：浅色 #FFFFFF，深色 #212121，用于设置面板、模型菜单和预览内容区。
- 高不透明主要表面颜色：浅色 #FFFFFFF2，深色 #212121F2，用于预览区标题栏等浮层。
- 悬停表面颜色：浅色 #F1F1F1，深色 #2B2B2B。
- 次级表面颜色：浅色 #EEEEEE，深色 #1D1D1D，用于代码块、表格标题、次级按钮和输出文件侧边栏。
- 气泡表面颜色：浅色 #F3F3F3，深色 #242424，用于用户消息与选择器激活热区。
- 输入表面颜色：`--input` 引用 `--bg`，浅色 #F8F8F8，深色 #171717；Composer 外壳和设置输入字段共享页面同色的输入表面。
- 主要文字颜色：浅色 #171717，深色 #F8F8F8。
- 主要阅读文字颜色：`--text-reading`，浅色 #444444，深色 #EEEEEE，用于最终答案与模型选择按钮。
- 次要文字颜色：浅色 #666666，深色 #D8D8D8。
- 低强调文字颜色：浅色 #888888，深色 #BABABA。
- 通用边界颜色：浅色 #E4E4E4，深色 #404040。
- 工作台分隔颜色：`--workbench-boundary` 使用 `color-mix(in srgb, var(--border) 45%, transparent)`，用于工作台内框外边缘、项目列表与消息区之间的竖直边界及右侧工作侧栏内部边缘；线宽为1px，边框及 `pointer-events: none` 伪元素共同保持原有交互命中区域。
- 侧栏拖拽线：`--workbench-resizer-line` 引用 `--workbench-boundary`，`--workbench-resizer-emphasis` 引用 `--border-strong`；左右侧栏的默认1px线与悬停、聚焦、待收起状态的2px强调线共同读取这两个令牌。
- 强调边界颜色：浅色 #AEAEAE，深色 #808080。
- 悬停反馈颜色：浅色 #1717170A，深色 #FFFFFF14。
- 导航反馈颜色：左侧导航悬停使用 `--nav-hover`，浅色 #17171714、深色 #FFFFFF1F；当前入口与设置模块选中使用 `--nav-selected`，浅色 #1717171F、深色 #FFFFFF29。导航选中态重于悬停态。
- 主要焦点颜色：浅色 #171717，深色 #F8F8F8。
- 选中背景颜色：浅色 #1717171A，深色 #F8F8F81F。
- 强调选中背景颜色：浅色 #17171733，深色 #F8F8F833。
- 文本选区颜色：浅色 #1717172E，深色 #F8F8F82E，与控件悬停反馈分别维护。
- 基础焦点环颜色：浅色 #1717173D，深色 #F8F8F83D。
- 强调焦点环颜色：浅色 #17171759，深色 #F8F8F859。
- 危险操作颜色：浅色 #C0362C，深色 #E07A6F。
- 危险操作背景颜色：浅色 #C0362C14，深色 #E07A6F1F。
- 成功状态颜色：浅色 #2F8A4E，深色 #7DC495。
- 警告状态颜色：浅色 #E0AF49，深色 #E6C168。
- 警告状态背景颜色：浅色 #E0AF4924，深色 #E6C1681F。
- 低强调警告背景颜色：浅色 #E0AF490D，深色 #E6C1680A。
- 警告文字颜色：浅色 #8A5A00，深色 #E9C46A。
- 轻量阴影颜色：浅色 #17171712，深色 #00000059。
- 搜索浮层阴影颜色：浅色 #1717171F，深色 #00000080。
- 中等阴影颜色：浅色 #17171721，深色 #0000008C。
- 强调阴影颜色：浅色 #17171726，深色 #00000099。
- 滚动条滑块颜色：浅色常态 #D8D8D8、悬停 #BABABA，深色常态 #545454、悬停 #7C7C7C；自绘滑块的渐变与内高光由滚动条令牌统一提供。
- 字号体系：界面使用语义字号令牌，`--ui-font-offset` 为0px，正文、代码、元信息、提示与标题使用基础字号；Canvas 界面显式字号共享同一偏移量，画布文字元素由文档自身的 `fontSize` 决定。
- 字号层级：细节9px、提示10px、说明11px、代码12px、元信息13px、正文14px、副标题15px、面板标题16px、二级标题17px、一级标题18px和空态标题20px；根字号与控件几何尺寸保持既有比例。
- 字体：系统字体 SF Pro Text 和苹方（回退 Hiragino Sans GB 与无衬线），页面继承字重为500，任务输入、模型选择与工具动作文字显式使用400；用户消息和普通模型正文目前继承页面字重。代码和文件内容使用 SF Mono 和系统等宽字体。
- 字形绘制：工作台文字采用当前操作系统与浏览器的默认字体平滑策略。
- 消息正文：字号14px，行高24px。
- 任务输入、模型选择按钮：字号14px，行高22px，字重400。
- 提示文字：字号10px，字重继承所在控件。
- 间距：4px，常用间距为4px，8px，12px，16px和24px。
- 面板尺寸：模型菜单宽250px，视口宽度700px及以下使用220px；常规窗口与触发按钮中心对齐，窄窗口沿按钮右侧对齐，与按钮间距8px。面板内边距4px、圆角16px，条目最小高度28px、水平内边距4px、相邻间距0，名称使用14px/22px/400并单行省略；面板最大高度300px，超出内容在内部滚动。
- 模型条目反馈：默认使用透明背景和次要文字颜色，悬停或聚焦使用次级表面颜色和主要文字颜色；选中条目使用主要文字颜色与16px check 图标。
- 项目操作菜单：宽200px、内边距4px、圆角10px；条目使用元信息字号13px、行高18px、字重400，最小高度28px、内边距4px 8px、圆角6px；图标16px，图文间距8px。
- 圆角：普通控件圆角为8px，浮层圆角为12px，工作台内框与设置页内容面板共同使用16px，Composer 圆角为20px。
- Composer 分隔：外壳使用输入表面和1px通用边界，以及 `0 1px 3px` 与 `0 8px 24px` 两层轻量阴影；悬停与内部聚焦沿用相同底色。
- 外壳几何：`--project-navigation-width` 为56px，导航轨道的实际宽度使用该值加 `--workbench-frame-gap`，当前合计64px；轨道横向内边距各8px，按钮到窗口左缘与内框左缘的距离均为8px。原生窗口控制按钮使用顶部预留区域。
- 外壳表面：`--workbench-shell-surface` 在浅色主题中使用 #EEEEEE，在深色主题中使用 #171717；外层应用壳和 `I / Project` 导航共同使用这一表面。
- 内框几何：`--workbench-frame-gap` 为8px，`--workbench-frame-radius` 为16px；内框左边缘位于导航宽度加留白处，顶部、右侧与底部各保留一份留白，外边框使用1px工作台分隔颜色。
- 设置页几何：左侧模块导航宽度复用 `--projects-panel-width`，顶部52px拖拽带使用 `--topbar-height`，Back 与模块入口使用其下方的交互区域；Back 圆角16px。右侧内容面板复用内框留白、圆角与表面；标题与列表共用左对齐线，顶部留白使用四份 `--workbench-frame-gap`（32px）并承载独立拖拽带，左右留白使用五份间距（40px），列表宽度随内框可用空间变化。General 列表沿用输入表面与8px圆角，外边框宽度0，行高48px，相邻行保留1px通用边界分隔线。页面标题使用 `--font-size-title`，模块名称与选择控件使用 `--font-size-body`。
- 共享选择控件：模型、Appearance、Language 共用 Select；默认触发器最小高度32px、圆角16px，紧凑触发器高度28px、圆角14px。设置入口边框宽度0、默认背景透明，悬停与展开使用 `var(--hover)` 和 `var(--text)`；正文统一使用14px字号、22px行高、400字重。共享 `chevron-right` 展开指示收起向右、展开顺时针旋转90度向下，选中项文字与共享16px `check` 图标使用主要文字颜色。
- 设置选择菜单：Portal 挂载至 `document.body`，右边缘与触发器右边缘对齐，使用 `align="end"`、`side="bottom"`、`sideOffset={8}`，顶边始终位于触发器底边下方8px；表面使用 `var(--surface)`，边框宽度0，圆角复用 `--workbench-frame-radius`（16px），阴影沿用现有浮层层级。
- 内框表面：`--workbench-frame-surface` 引用 `--surface`，浅色为 #FFFFFF，深色为 #212121；标题栏、项目列与消息主列共同呈现这一表面。
- 内框抬升：`--workbench-frame-shadow` 使用单层贴边阴影 `0 1px 3px var(--shadow-soft)`；表面色差、1px浅边框和贴边阴影共同形成 Elevation 层次。
- 内框布局：项目列表、消息主列与右侧工作侧栏使用三列，纵向使用52px标题行与剩余内容行，`--topbar-height` 统一提供标题高度；项目列跨越两行，主标题栏占据中间列至右端的第一行，消息与右侧面板使用第二行。内框裁剪圆角边缘，各滚动父容器采用可收缩的宽高约束。
- 项目导航表面：外层导航轨道使用 `--workbench-shell-surface`，内框项目列表使用 `--workbench-frame-surface`，项目标题和内部列边缘使用1px工作台分隔颜色；项目操作菜单使用主要表面颜色、通用边界和浮层圆角。
- 项目列表尺寸：默认宽度220px，最小宽度180px；展开时使用当前有效宽度，收起时使用0宽度，内框第一列由壳体实际宽度自动确定。有效最大宽度使用项目列与消息主列的局部可用空间减去消息主列最小宽度360px。
- 项目列表拖拽：边界热区8px，可见边界1px，待收起时使用2px强调边界；收起阈值为最小宽度减48px，即132px；键盘步进16px，Shift步进64px，双击恢复默认宽度。
- 项目列表过渡：开合宽度使用180ms与标准缓动，指针调整时使用帧节流直接更新，减少动态效果偏好使用即时切换；列表正文按当前有效宽度排版，开合过程由壳体裁切。
- 项目入口反馈：`I` 和 `Project` 导航入口使用次要文字颜色，悬停与选中共同采用 `--hover` 和主要文字颜色，与右上角图标按钮的悬停及激活背景保持一致；项目列表条目的悬停使用悬停反馈颜色，选中使用选中背景和主要文字颜色，键盘聚焦沿用基础焦点环。
- 项目文字与按钮：项目名称使用正文14px，列表标题使用面板标题16px，控件圆角沿用普通控件8px；列表开合按钮在项目标题与内框主标题栏之间切换位置，两个位置共用30乘30px热区与图标按钮反馈。
- 应用导航标识：使用透明底的内部矢量符号，填充继承入口当前文字颜色；原始应用图标继续提供 Dock 与 favicon 的完整图像。
- 边界宽度：1px。
- 动画：快速状态动画时长为120ms，浮层动画时长为150ms，标准交互动画时长为180ms，内容展开动画时长为200ms。标准动画使用先快后慢的缓动曲线。
- 图标：纯图标按钮使用统一的线性矢量图标，图标保持相同的描边风格。纯图标按钮提供 Tooltip 和无障碍名称。
