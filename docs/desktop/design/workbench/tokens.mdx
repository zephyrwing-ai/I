字体使用系统字体 SF Pro Text 和苹方（回退 Hiragino Sans GB 与无衬线），页面继承字重为500，任务输入、模型选择与工具动作文字显式使用400；用户消息和普通模型正文目前继承页面字重。代码和文件内容使用 SF Mono 和系统等宽字体。

- 消息正文：字号14px，行高24px。
- 任务输入、模型选择按钮：字号14px，行高22px，字重400。
- 提示文字：字号10px，字重400。

基础间距单位为4px，常用间距为4px，8px，12px，16px和24px。

面板尺寸：模型选择面板宽度固定为250px（窄窗口下220px），面板与触发按钮中心对齐且间距8px，面板内边距为4px；条目最小高度为28px，水平内边距为4px，圆角为16px，名称使用正文字型14px/22px/400、默认次要文字颜色并单行省略，条目悬停或选中时背景使用悬停反馈颜色并切换为主要文字颜色，选中标记为check图标16px使用主要文字颜色，相邻条目之间不设置额外间距；面板最大高度为300px（内容超出时内部滚动）。

普通控件圆角为8px，浮层圆角为12px，设置面板圆角为14px，Composer 圆角为16px。

通用边界宽度为1px。

快速状态动画时长为120ms，浮层动画时长为150ms，标准交互动画时长为180ms，内容展开动画时长为200ms。标准动画使用先快后慢的缓动曲线。
