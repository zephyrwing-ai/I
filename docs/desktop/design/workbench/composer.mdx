Composer。

- 位置：固定在消息主列底部，覆盖在消息流滚动容器之上、不参与滚动（覆盖关系见滚动条）。
- 尺寸：最大宽度760px，最小高度116px。
- 材料：主要表面颜色，16px圆角，通用边界，轻量阴影。
- 内边距：顶部和水平14px，底部10px。
- 布局：附件区，任务输入区和内部操作带三个区域共用同一表面，区域之间8px间距。
- 悬停：悬停表面颜色。
- 焦点：内部焦点出现时外观保持与未聚焦一致。
- 高度：根据附件和输入高度向上扩展。
- 重排：输出文件侧边栏改变宽度时，Composer 在消息主列内同步重排。

附件区。

- 位置：任务输入上方。
- 空状态：不占据高度。
- 间距：附件之间8px，根据可用宽度换行。
- 尺寸：高度42px，最大宽度230px。
- 材料：输入表面颜色，10px圆角，通用边界。
- 内容：文件图标（图片使用 image 图标，其余使用 file 图标，15px），文件名11px五百六十字重，文件大小9px低强调文字颜色，移除入口26px圆形按钮。
- 草稿：Renderer 保存尚未发送的附件草稿，重复选择同一文件时按附件标识合并。
- 移除：只修改草稿不删除用户文件，运行期间移除入口禁用。

上传文件按钮。

- 位置：内部操作带左侧。
- 热区：28乘28px 圆形。
- 材料：透明背景，次要文字颜色，悬停使用悬停反馈颜色和主要文字颜色。
- 图标：加号图标（plus）18px，与发送停止按钮图标同尺寸。
- 交互：在用户触发按钮后打开系统文件选择器，并把选择结果加入附件草稿。
- 运行期间：禁用。

任务输入框。

- 位置：附件区和内部操作带之间。
- 材料：透明背景，没有独立边界和阴影。
- 尺寸：最小40px，最大180px。
- 文字：14px，行高22px，Placeholder 为 What's up?。
- 高度增长：根据输入内容调整高度，超过最大高度后输入框内部滚动。
- 提交：Enter 提交任务，Shift Enter 插入换行；输入法（拼音等）组字期间的 Enter 只完成候选确认并上屏，组字结束后再次 Enter 才提交，提交判断读取 keydown 原生事件的 isComposing 标记区分组字状态与真实提交。
- 运行期间：禁用，百分之七十二透明度，无法聚焦和输入。
- 提交后清理：通过本地发送条件检查后，调用 `onRun` 并立即清空任务文本和附件草稿、重置输入框高度；不等待 Main 的运行确认。用户消息在 Main 确认运行成功、Renderer 分发 `runAccepted` 后进入消息列。
- 待改进边界：启动被拒绝时当前不会恢复已清空的草稿；草稿恢复应作为后续交互改进，不将丢失输入视为设计要求。

模型选择按钮。

模型选择状态与布局恢复。

- Composer 持有唯一的 `selectedModelOptionId`，并以它构造每次运行的 `RunRequest`。
- Composer 在 Renderer 首次创建时同步读取版本化的 `localStorage` 布局快照 `workbench.modelPickerLayout.v1`。快照包含 `modelOptionId`、最近一次确认的 `displayName` 和按钮宽度；因此提供商目录通过 IPC 返回前，Composer 可以直接恢复上一次的名称与几何尺寸。
- 旧版本的 `workbench.modelOptionId` 继续作为兼容入口。新布局快照与旧选择标识不一致时，以旧标识中的最新用户选择为准，并等待当前目录重新确认布局。
- ProviderCatalog 通过 `providers:list` 提供模型目录数据；目录完成加载后，Composer 按 `modelOptionId` 校验模型是否仍在最近一次拉取目录中。模型被远端移除时清除当前选择，后续目录重新出现时可以再次匹配本地偏好。
- 有效布局快照与当前模型名称一致时，启动直接沿用缓存宽度，不执行文本测量，也不播放宽度过渡。没有快照、快照损坏或模型显示名称发生变化时，Composer 只在布局需要时重新测量一次；启动阶段的校正不播放动画。
- 本地偏好属于 Renderer 的界面状态，不写入 ProviderStore、提供商配置或会话存储。Main 继续负责提供商、模型目录和加密凭据；App 负责提交 Composer 构造的运行请求。

- 位置：内部操作带右侧，发送停止按钮左侧。
- 宽度：按钮自适应，宽度完全由名称文字与水平间距构成（左右边距各8px，名称与展开指示之间12px，展开指示15px），名称按自然宽度完整显示，同一行剩余空间不足时单行省略；启动时优先应用布局快照中的宽度，窗口可用空间不足时由当前布局约束截断。用户主动切换模型后，按钮只为这次名称变化执行一次文本测量，并在180ms内平滑过渡到新宽度；布局校正不改变模型业务状态。
- 尺寸：高度28px，圆角16px。
- 材料：透明背景，主要阅读文字颜色；悬停和打开时仅调整文字与展开指示颜色。
- 文字：当前模型名称水平居中，使用正文字型（SF Pro Text／苹方，14px，字重400），颜色与模型消息正文一致（主要阅读文字颜色）；展开指示（chevron-right 15px）与名称间距12px、参与布局排位；收起时指向右，展开后逆时针旋转90度指向上，名称过长时单行省略。
- 加载态：有有效布局快照时，模型目录读取期间直接显示缓存的模型名称并保持禁用；没有可用缓存时显示读取模型…并保持禁用。目录读取完成后显示已校验的模型名称或选择模型。
- 空态：未选择模型时显示选择模型。
- 不显示内容：提供商名称，Model ID，API Base URL 和其他连接元数据。
- 交互：在用户触发按钮后打开模型面板并更新 aria expanded。选择其他模型后关闭面板，将焦点返回模型选择按钮，更新 Composer 的 `selectedModelOptionId`，立即写入模型选择偏好；按钮完成一次新宽度测量后同步更新布局快照，并更新下一次运行使用的 `modelOptionId`。重新选择当前模型不会触发无意义的宽度动画或测量。
- 运行期间：禁用。

模型选择面板。

- 位置：直接位于模型选择按钮上方，与按钮中心对齐，宽度固定250px（窄窗口下220px），与按钮间距8px。
- 材料：主要表面颜色，4px内边距，16px圆角，通用边界，中等阴影。
- 动画：以右下角为变换原点，通过4px向下位移，轻微缩放和透明度变化完成150ms展开动画。
- 尺寸：条目最小高度28px，面板最大高度300px（内容超出时内部滚动），相邻条目之间不设置额外间距，选中和悬停状态仅调整文字颜色，当前选中条目在名称右侧显示选中标记。
- 空状态：没有可用模型时显示尚未添加可用模型的空状态。
- 键盘：面板使用列表语义，条目使用选项语义并提供选中状态，Arrow Down 和 Arrow Up 移动焦点，Home 和 End 跳转到首尾条目。
- 关闭：Esc 关闭面板并把焦点返回模型选择按钮，点击模型选择区域外部关闭面板。
- 内容：只渲染最近一次模型拉取返回且当前凭据可用的模型。
模型条目。
- 尺寸：最小高度28px，水平内边距4px，圆角16px，宽度占满面板内容区。
- 材料：透明背景，名称使用次要文字颜色；悬停或选中时名称切换为主要文字颜色。
- 文字：名称使用正文字型（14px，行高22px，字重400），单行省略。
- 布局：名称位于条目左侧，选中标记位于右侧，两端对齐。
- 选中标记：check 图标16px，使用主要文字颜色，仅当前选中条目显示。
- 间距：相邻条目之间不设置额外间距。

发送停止按钮。

- 位置：内部操作带右下角，与模型选择按钮之间7px间距。
- 尺寸：28乘28px 圆形。
- 材料：主要文字颜色作为背景和白色图标。
- 图标：发送状态使用向上箭头图标18px，停止状态使用停止图标18px，图标随状态切换在120ms内淡入。
- 禁用：发送禁用状态透明度为百分之三十八，停止状态下的禁用透明度为百分之七十二。
- 反馈：悬停时亮度降低为百分之九十，按下状态在80ms内缩放到原尺寸的百分之九十四。
- 发送条件：任务文本非空，当前模型可用，当前没有运行中的实例。
- 交互：触发发送后保持按钮位置不变并切换为停止状态；正在停止期间按钮自身禁用并声明忙碌状态；运行终态到达后恢复发送状态，并保留已经产生的消息和工具活动。

运行期间状态。

- 定义：运行期间指当前存在尚未结束的运行实例，覆盖启动，运行和停止过程。
- 禁用的控件：任务输入框，文件上传按钮，附件移除入口和模型选择按钮。
- 发送入口：发送停止按钮保持位置不变并切换为停止状态，正在停止期间按钮自身禁用并声明忙碌状态。
- 恢复：运行终态到达后恢复 Composer 全部控件和发送状态，并保留已经产生的消息和工具活动。
- 提示文字：任务文本非空而当前模型不可用时，发送按钮保持禁用，Composer 保留任务文本，外壳底部左侧显示提示文字。
- 提示规格：10px文字，危险操作颜色，内容为请选择可用模型。
