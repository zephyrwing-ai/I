Composer。

- 位置：固定在消息主列底部，覆盖在消息流滚动容器之上、不参与滚动（覆盖关系见滚动条）。
- 尺寸：最大宽度760px，最小高度116px。
- 材料：主要表面颜色，18px圆角，通用边界，轻量阴影。
- 内边距：顶部和水平14px，底部10px。
- 布局：附件区，任务输入区和内部操作带三个区域共用同一表面，区域之间8px间距。
- 悬停：悬停表面颜色。
- 焦点：获得内部焦点时只显示一组主要焦点边界和焦点环，任务输入框自身不显示独立焦点环。
- 高度：根据附件和输入高度向上扩展。
- 重排：输出文件侧边栏改变宽度时，Composer 在消息主列内同步重排。

附件区。

- 位置：任务输入上方。
- 空状态：不占据高度。
- 间距：附件之间8px，根据可用宽度换行。
- 尺寸：高度42px，最大宽度230px。
- 材料：输入表面颜色，10px圆角，通用边界。
- 内容：文件图标（图片使用 image 图标，其余使用 file 图标，15px），文件名11px五百六十字重，文件大小9px低强调文字颜色，移除入口26px圆形按钮。
- 草稿：Renderer 保存尚未发送的附件草稿，重复选择同一文件时按附件标识合并。
- 移除：只修改草稿不删除用户文件，运行期间移除入口禁用。

上传文件按钮。

- 位置：内部操作带左侧。
- 热区：36乘36px 圆形。
- 材料：透明背景，次要文字颜色，悬停使用悬停表面颜色和主要文字颜色。
- 交互：在用户触发按钮后打开系统文件选择器，并把选择结果加入附件草稿。
- 运行期间：禁用。

任务输入框。

- 位置：附件区和内部操作带之间。
- 材料：透明背景，没有独立边界和阴影。
- 尺寸：最小54px，最大180px。
- 文字：14px，行高22px，Placeholder 为 do anything。
- 高度增长：根据输入内容调整高度，超过最大高度后输入框内部滚动。
- 提交：Enter 提交任务，Shift Enter 插入换行。
- 运行期间：禁用，百分之七十二透明度，无法聚焦和输入。
- 提交后清理：清空任务文本和附件草稿，重置输入框高度；消息已经在消息列中，Composer 不保留副本。

模型选择按钮。

- 位置：内部操作带右侧，发送停止按钮左侧。
- 宽度：按钮和模型面板宽度一致，桌面宽度290px，窄窗口下220px。
- 尺寸：高度36px，水平内边距30px，圆角8px。
- 材料：透明背景，次要文字颜色；悬停和打开时使用悬停表面颜色和主要文字颜色。
- 文字：当前模型名称水平居中，展开指示（chevron-down 15px）独立定位在右侧，名称过长时单行省略。
- 加载态：模型目录读取期间显示读取模型…并保持禁用，读取完成后恢复显示当前可用模型名称。
- 空态：未选择模型时显示选择模型。
- 不显示内容：提供商名称，Model ID，API Base URL 和其他连接元数据。
- 交互：在用户触发按钮后打开模型面板并更新 aria expanded。选择模型后关闭面板，将焦点返回模型选择按钮，并更新下一次运行使用的 modelOptionId。
- 运行期间：禁用。

模型选择面板。

- 位置：直接位于模型选择按钮上方，与按钮保持相同宽度。
- 材料：主要表面颜色，8px内边距，12px圆角，通用边界，中等阴影。
- 动画：以右下角为变换原点，通过4px向下位移，轻微缩放和透明度变化完成150ms展开动画。
- 布局：不显示提供商分组标题，主机地址，API Base URL 和模型数量，每个条目只显示一行可读名称和当前选择状态。
- 尺寸：条目最小高度36px，垂直内边距4px，水平内边距9px，相邻条目之间不设置额外间距，选中和悬停状态使用选中背景颜色，当前选中条目在名称右侧显示选中标记。
- 空状态：没有可用模型时显示尚未添加可用模型的空状态。
- 键盘：面板使用列表语义，条目使用选项语义并提供选中状态，Arrow Down 和 Arrow Up 移动焦点，Home 和 End 跳转到首尾条目。
- 关闭：Esc 关闭面板并把焦点返回模型选择按钮，点击模型选择区域外部关闭面板。
- 内容：只渲染已经导入且可用的模型。当前选择在刷新后变为不可用时，模型选择按钮继续显示原模型名称并禁用发送，用户重新选择可用模型后恢复。

发送停止按钮。

- 位置：内部操作带右下角，与模型选择按钮之间7px间距。
- 尺寸：24乘24px 圆形。
- 材料：主要文字颜色作为背景和白色图标。
- 图标：发送状态使用向上箭头图标18px，停止状态使用停止图标18px，图标随状态切换在120ms内淡入。
- 禁用：发送禁用状态透明度为百分之三十八，停止状态下的禁用透明度为百分之七十二。
- 反馈：悬停时亮度降低为百分之九十，按下状态在80ms内缩放到原尺寸的百分之九十四。
- 发送条件：任务文本非空，当前模型可用，当前没有运行中的实例。
- 交互：触发发送后保持按钮位置不变并切换为停止状态；正在停止期间按钮自身禁用并声明忙碌状态；运行终态到达后恢复发送状态，并保留已经产生的消息和工具活动。

运行期间状态。

- 定义：运行期间指当前存在尚未结束的运行实例，覆盖启动，运行和停止过程。
- 禁用的控件：任务输入框，文件上传按钮，附件移除入口和模型选择按钮。
- 发送入口：发送停止按钮保持位置不变并切换为停止状态，正在停止期间按钮自身禁用并声明忙碌状态。
- 恢复：运行终态到达后恢复 Composer 全部控件和发送状态，并保留已经产生的消息和工具活动。
- 提示文字：任务文本非空而当前模型不可用时，发送按钮保持禁用，Composer 保留任务文本，外壳底部左侧显示提示文字。
- 提示规格：10px文字，危险操作颜色，内容为请选择可用模型。
