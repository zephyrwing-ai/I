提供商编辑视图。

- 字段范围：提供商名称，API Base URL 和 API Key。当前发现与运行仅使用 OpenAI 兼容协议，名称和域名不切换到 Anthropic 或 Google 原生协议。
- 字段尺寸：高度38px，水平内边距10px，圆角8px。
- 字段材料：输入表面颜色，通用边界；聚焦时显示主要焦点颜色和单一外部焦点环。
- 字段标签：11px文字，次要文字颜色，与输入框保持5px间距。
- 字段间距：12px。
- 提供商名称：文本输入，Placeholder 为例如 OpenAI。
- API Base URL：URL 输入，Placeholder 为 https://api.example.com/v1，关闭拼写检查。
- API Key：密码输入，关闭自动补全和拼写检查。新建时 Placeholder 为输入 API Key，编辑时 Placeholder 为留空使用已保存凭据。
- 草稿：连接内容和模型选择属于编辑草稿，保存成功前保留在 Renderer 本地，与已保存数据分离。
- 初始焦点：进入编辑视图时焦点直接落在提供商名称输入框。
- 禁用状态：保存中或发现模型期间，字段和模型选择全部禁用。

返回提供商列表按钮。

- 位置：编辑视图标题左侧。
- 尺寸：热区30乘30px，圆角8px。
- 材料：透明背景，低强调文字颜色。
- 图标：chevron-left 语义图标16px。
- 交互：触发后返回提供商列表视图。保存动作只由保存提供商按钮触发，本按钮只改变视图状态并丢弃编辑草稿。
- 无障碍：提供 Tooltip，无障碍名称使用返回提供商列表。

模型搜索输入框。

- 位置：模型发现区顶部左侧。
- 尺寸：高度38px，水平内边距10px，圆角8px。
- 材料：输入表面颜色，通用边界。
- 交互：按模型标识和可读名称做大小写无关过滤。过滤只更新可见列表，每行的选中状态保持原值。
- 处理位置：过滤在 Renderer 本地完成。

全选模型入口。

- 位置：模型搜索输入框右侧。
- 尺寸：高度38px，水平内边距9px，圆角8px。
- 材料：主要表面颜色，通用边界。
- 状态：当前结果全部选中时勾选；当前结果部分选中时显示混合选择状态；当前结果为空时禁用。
- 交互：触发后对当前结果中全部模型做选中或取消选中。
- 处理位置：操作完全在本地草稿中完成。

获取模型列表按钮。

- 位置：模型搜索和全选区域下方。
- 尺寸：最小高度34px，水平内边距12px，圆角9px。
- 材料：主要表面颜色，通用边界，次要文字颜色；禁用状态透明度为百分之四十五。
- 启用条件：API Base URL 已填写，且 API Key 已填写或已有提供商已保存凭据。
- 加载状态：获取期间显示转圈动画并切换文字为正在获取，连接字段暂时禁用。
- 发现结果（新建）：新发现的模型全部默认选中，以已保存状态列入。
- 发现结果（编辑）：原有选中状态保持；新发现的模型以新增状态列出，默认未选中；在远端消失且之前曾选中的模型保持选中并标记为不可用。
- 状态提示：获取成功显示已获取 N 个模型，失败时显示错误说明并以警报语义呈现（警告图标15px，危险操作颜色）。

取消获取按钮。

- 位置：获取模型列表按钮右侧。
- 显示条件：只在模型发现进行中显示。
- 尺寸：最小高度34px，圆角9px。
- 材料：透明背景，次要文字颜色。
- 交互：触发后取消当前发现请求并恢复连接字段和获取入口。取消后到达的响应按请求标识丢弃，只保留当前草稿状态。
- 提示：取消后状态区域显示已取消获取模型。

模型选择数量。

- 位置：发现状态与模型列表之间。
- 文字：11px，低强调文字颜色。
- 内容：已选数量和当前模型总数，例如选择 2/5 模型。
- 计算：按草稿中所有行实时计算。
- 关联：选择数量为零时保存提供商按钮保持禁用。

模型发现列表。

- 位置：选择数量下方。
- 尺寸：最大高度220px，内容超出时列表内部滚动，列表使用9px圆角和通用边界。
- 条目尺寸：最小高度42px，垂直内边距7px，水平内边距9px。
- 条目布局：复选框15px，模型标识占剩余宽度，状态标签靠右，列间距8px；相邻条目之间使用通用边界分隔。
- 条目文字：模型标识12px四百五十字重。
- 状态标签：9px文字，新增使用成功状态颜色，不可用使用警告文字颜色；不可用行使用低强调警告背景。
- 空状态：显示尚无模型，请先获取模型列表。
- 关联：保存中或发现期间全部禁用。

取消提供商按钮。

- 位置：编辑视图底部操作区。
- 尺寸：最小高度34px，圆角9px。
- 材料：透明背景，次要文字颜色；保存中禁用，禁用透明度为百分之四十五。
- 交互：触发后丢弃当前连接草稿和模型选择草稿，返回提供商列表。
- 处理位置：操作完全在 Renderer 本地完成，不产生部分提供商数据。

保存提供商按钮。

- 位置：编辑视图底部最右侧。
- 尺寸：最小高度34px，圆角9px。
- 材料：主要文字颜色背景，白色文字；禁用透明度为百分之四十五。
- 启用条件：已选中至少一个模型且当前处于空闲状态。
- 保存内容：连接字段和选中的模型标识。
- 校验顺序：依次检查提供商名称，API Base URL，API Key（新建时）和已选模型数，发现缺失时显示对应提示。
- 提交状态：保存进行中按钮显示正在保存，面板保留当前内容。
- 成功处理：API Key 输入框清空，刷新 Composer 模型目录后返回提供商列表。当前选择仍在已导入模型中时保留；如果编辑时取消导入该模型，选择清空，恢复为选择模型状态。目录回读失败显示读取错误，但不撤销已经成功保存的提供商。
- 无障碍：提供明确的操作文字。

模型发现与保存边界。

- Main 使用 Bearer 认证请求 OpenAI 兼容模型列表，按 Base URL 路径生成候选 `/models` 或 `/v1/models` 端点；不提供原生 Anthropic、Google 模型发现。
- 发现请求整体超时为12秒；支持同源分页，遇到认证失败直接结束。取消发现由请求标识关联到 Main 的 AbortController。
- 保存只提交选中的模型及其可用状态，不会在保存时重新验证连接。修改 URL 或凭据后，需要主动获取模型列表才能核验新连接。
- 同一提供商中仍被保留的模型沿用 modelOptionId；取消导入的模型从保存目录移除。
