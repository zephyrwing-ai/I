提供商编辑视图。

- 字段范围：提供商名称，API Base URL 和 API Key。当前发现与运行由 OpenAI 兼容适配器统一处理，提供商名称与域名承担连接配置职责。
- 字段尺寸：高度38px，水平内边距10px，圆角8px。
- 字段材料：输入表面颜色，通用边界；聚焦时显示主要焦点颜色和单一外部焦点环。
- 字段标签：11px文字，次要文字颜色，与输入框保持5px间距。
- 字段间距：12px。
- 提供商名称：文本输入，Placeholder 为例如 OpenAI。
- API Base URL：URL 输入，Placeholder 为 https://api.example.com/v1，关闭拼写检查。
- API Key：密码输入，关闭自动补全和拼写检查；右侧提供 eye/eye-off 按钮切换当前草稿的显示状态。新建或同 origin 已保存凭据为空时提示输入 API Key；编辑时使用空凭据草稿与已保存状态提示。保存时 Main 使用 `safeStorage` 加密并将密文写入本地 Provider JSON，重启后继续解密使用。API Base URL 的协议、主机或端口变化时，显示 `Enter an API Key for the new provider address.` 提示，并在输入凭据前禁用获取与保存；同 origin 的路径调整允许留空复用已保存凭据。
- 草稿：连接内容和模型选择属于编辑草稿，保存成功前保留在 Renderer 本地，与已保存数据分离。
- 初始焦点：进入编辑视图时焦点直接落在提供商名称输入框。
- 禁用状态：保存中或发现模型期间，字段和模型选择全部禁用。

返回提供商列表按钮。

- 位置：编辑视图标题左侧。
- 尺寸：热区30乘30px，圆角8px。
- 材料：透明背景，低强调文字颜色。
- 图标：统一使用 chevron-right 语义图标15px，返回状态通过旋转180度实现。
- 交互：触发后返回提供商列表视图。保存动作只由保存提供商按钮触发，本按钮只改变视图状态并丢弃编辑草稿。
- 无障碍：提供 Tooltip，无障碍名称使用返回提供商列表。

模型搜索输入框。

- 位置：模型发现区顶部左侧。
- 尺寸：高度38px，水平内边距10px，圆角8px。
- 材料：输入表面颜色，通用边界。
- 交互：按模型标识和可读名称做大小写无关过滤。过滤只更新可见列表，每行的选中状态保持原值。
- 处理位置：过滤在 Renderer 本地完成。

全选模型入口。

- 位置：模型搜索输入框右侧。
- 尺寸：高度38px，水平内边距9px，圆角8px。
- 材料：主要表面颜色，通用边界。
- 状态：当前结果全部选中时勾选；当前结果部分选中时显示混合选择状态；当前结果为空时禁用。
- 交互：触发后对当前结果中全部模型做选中或取消选中。
- 处理位置：操作完全在本地草稿中完成。

获取模型列表按钮。

- 位置：模型搜索和全选区域下方。
- 尺寸：最小高度34px，水平内边距12px，圆角9px。
- 材料：主要表面颜色，通用边界，次要文字颜色；禁用状态透明度为百分之四十五。
- 启用条件：API Base URL 已填写，且 API Key 已填写或已有同 origin 的已保存凭据。
- 加载状态：获取期间显示转圈动画并切换文字为正在获取，连接字段暂时禁用。
- 发现结果：模型列表完全替换为本次远端返回的结果，所有返回模型默认选中；本次远端结果之外的模型从草稿中移除。
- 状态提示：获取成功显示模型拉取成功，失败时显示错误说明并以警报语义呈现（警告图标15px，危险操作颜色）。

取消获取按钮。

- 位置：获取模型列表按钮右侧。
- 显示条件：只在模型发现进行中显示。
- 尺寸：最小高度34px，圆角9px。
- 材料：透明背景，次要文字颜色。
- 交互：触发后取消当前发现请求并恢复连接字段和获取入口。取消后到达的响应按请求标识丢弃，只保留当前草稿状态。
- 提示：取消后状态区域显示已取消获取模型。

模型选择数量。

- 文字：11px，低强调文字颜色。
- 内容：已选数量和当前模型总数，例如选择 2/5 模型。
- 计算：按草稿中所有行实时计算。
- 关联：选择数量为零时保存提供商按钮保持禁用。

模型发现列表。

- 位置：选择数量下方。
- 尺寸：最大高度220px，内容超出时列表内部滚动，列表使用9px圆角和通用边界。
- 条目尺寸：最小高度42px，垂直内边距7px，水平内边距9px。
- 条目布局：复选框15px，模型标识占剩余宽度，列间距8px；相邻条目之间使用通用边界分隔。
- 条目文字：模型标识12px四百五十字重。
- 状态呈现：模型条目使用名称与选中标记表达状态。
- 空状态：显示尚无模型，请先获取模型列表。
- 关联：保存中或发现期间全部禁用。

模型容量配置。

- 位置：每个模型条目下方的 `Model limits` 折叠区，展开后显示窗口与最大输出两个输入框。
- 窗口字段：`Context window tokens` 使用整数文本输入和数字键盘提示，展示已发现、目录补齐或已保存的模型窗口；能力为空时显示 `Unknown` 占位。
- 输出字段：`Max output tokens (optional)` 展示最大输出能力，留空表示该字段由已有资料解析；任务的实际输出预留由上下文策略计算。
- 草稿：编辑任一容量字段时保存该模型独立的容量草稿，与连接和选中状态一起等待保存；同 origin 刷新后的模型资料保留已保存的手动配置。
- 校验：窗口使用正安全整数，已填写的输出使用正安全整数并小于等于窗口；已有 `maxInputTokens` 保留并要求其小于等于窗口，错误显示在编辑视图状态区。
- 保存：手动容量使用 `source: manual`，窗口、可选输出与已有输入上限随所选模型提交，ProviderStore 将能力资料随模型记录持久化。
- 运行：Composer 选定模型后，Main 将保存的能力经 Runner 传入 Runtime，上下文模块据此计算双阈值；具体预算规则见[上下文管理](../../../agent/context-management.mdx)。
- 状态：保存和模型发现期间容量输入沿用字段禁用状态。

取消提供商按钮。

- 位置：编辑视图底部操作区。
- 尺寸：最小高度34px，圆角9px。
- 材料：透明背景，次要文字颜色；保存中禁用，禁用透明度为百分之四十五。
- 交互：触发后丢弃当前连接草稿和模型选择草稿，返回提供商列表。
- 处理位置：操作完全在 Renderer 本地完成，提供商数据在保存成功后整体持久化。

保存提供商按钮。

- 位置：编辑视图底部最右侧。
- 尺寸：最小高度34px，圆角9px。
- 材料：主要文字颜色背景，白色文字；禁用透明度为百分之四十五。
- 启用条件：已选中至少一个模型，API Key 已填写或已有同 origin 的已保存凭据，且当前处于空闲状态。
- 保存内容：连接字段、选中的模型标识与对应能力资料，包含经过校验的手动容量配置。
- 校验顺序：依次检查提供商名称，API Base URL，可用 API Key 和已选模型数，发现缺失时显示对应提示；Main 再校验 URL、模型选择与凭据复用边界。
- 提交状态：保存进行中按钮显示正在保存，面板保留当前内容。
- 成功处理：API Key 输入框清空，刷新 Composer 模型目录后返回提供商列表。当前选择仍在本次拉取返回的模型中时保留；模型被远端移除时清除当前选择。目录回读失败显示读取错误，已经成功保存的提供商继续保留。
- 无障碍：提供明确的操作文字。

模型发现与保存边界。

- Main 使用 Bearer 认证请求 OpenAI 兼容模型列表，按 Base URL 路径生成候选 `/models` 或 `/v1/models` 端点；Anthropic、Google 原生模型发现属于后续协议扩展。
- 能力来源：Main 解析服务返回的窗口、输入与输出能力，官方原生端点按精确模型标识查本地目录补齐，来源记录为 `provider` 或 `catalog`；手动设置在同 origin 内优先保留。
- 发现请求整体超时为12秒；支持同源分页，遇到认证失败直接结束。取消发现由请求标识关联到 Main 的 AbortController。
- 保存提交选中的模型标识，连接验证通过主动获取模型列表完成。修改 URL 或凭据后，需要主动获取模型列表才能核验新连接。
- 获取使用当前草稿的显式 API Key，或同 origin 的已保存凭据；获取成功更新当前草稿，连接持久化由保存操作完成。保存和获取都由 Main 拒绝跨 origin 自动复用旧凭据，Main 与 Renderer 共同执行这项凭据边界。
- 每个提供商拥有独立 providerProfileId 和密文；相同模型标识可存在于不同提供商中，其 modelOptionId 独立。每个提供商的凭据按所属记录独立更新。
- 同一提供商中仍被保留的模型沿用 modelOptionId；取消导入的模型从保存目录移除。
