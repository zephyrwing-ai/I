弹性回弹滚动。

消息流 `.stream-scroll` 与输出文件列表 `.output-file-list` 共用弹性回弹交互：边界内使用原生滚动，到达边界后将持续输入转为阻尼位移，输入结束后平滑归位。交互分为正常滚动、边界跟手、松手回弹三个阶段。

滚动条（消息流）。

- 轨道：宽12px、背景透明，位于消息主列最右侧，贯穿滚动区域至列底，与 Composer 区域重叠。消息内容与 Composer 共用最大760px的居中列。
- 滑块：视觉宽度8px、端头圆角8px，与轨道右缘保持2px空隙，顶部和底部行程各保留2px。常态长度为 `clamp(视口高 × 视口高 ÷ 内容总高, 48px, 72px)`；短内容使用72px，长内容逐步收至48px。
- 玻璃质感：实心胶囊采用垂直微渐变，顶部 #C8C0B5 过渡至45%位置的 #B9B0A3，叠加0.5px暖白色内高光 `rgba(255,252,247,0.6)`。
- 悬停与拖拽：渐变加深至 #A79C8F 和 #968A7B，内高光在120ms内调整为 `rgba(255,252,247,0.35)`。
- 显示与操作：滑块持续可见，拖拽位置按原生滚动范围换算；内容长度与视口尺寸变化时同步更新常态长度和位置。

滚动几何。

- 元素分为滚动容器、布局裁剪层、位移内容层。布局裁剪层保持正常文档高度并裁剪位移后的视觉溢出；位移内容层承载 `translateY(offset)`。
- 原生滚动范围由正常布局确定：`maxScroll = max(0, scrollHeight − clientHeight)`。顶部为 `scrollTop = 0`，底部为 `scrollTop = maxScroll`，边界判断采用像素容差适配小数滚动位置。
- 跟手与回弹期间，原生滚动范围保持稳定，滚动容器停靠对应边界，内容通过内部位移呈现弹性。
- 短内容的滚动范围为零，两个方向的输入均可进入跟手；连续反向输入先抵消已有拉力，再沿新方向跟手。

输入与跟手。

- 边界内的普通输入走原生滚动路径；越界输入由可取消的 `wheel`、`touchmove` 监听器接管。wheel 增量按 `deltaMode` 换算为像素，触摸增量按相邻手指位置计算。
- 代码块与工具输出的内部滚动区优先消耗自身方向上的滚动余量，到达边界后由外层接续。横向手势与缩放手势沿用浏览器交互；系统启用减少动态效果时采用原生滚动。
- 当前拉力记录越界方向与累计输入强度。位移绝对值为 `MAX × (1 − 1 / (pull / SATURATION + 1))`，其中 MAX = 96px、SATURATION = 400px；累计拉力400px对应48px位移，初始跟手比例为0.24，位移逐渐趋近96px。
- 顶部越界时内容向下移动，底部越界时内容向上移动，视觉方向跟随手势拉动方向。
- 反向输入先抵消当前拉力，抵消后的余量交还原生 `scrollTop`；跟手与回弹共用这套连续交接规则。
- 回弹途中再次输入时，以当前位移反算拉力并继续跟手，保持交接前后的视觉位置连续。

松手回弹。

- wheel 最后一次输入后静默40ms进入回弹；同一轮连续 wheel 手势（相邻输入间隔不超过160ms，`ELASTIC_GESTURE_GAP`）中，越界跟手累计超过200ms（`ELASTIC_TRACK_MAX`）后剩余惯性事件不再延长位移并进入回弹；手势间隔超过160ms视为新手势，重新获得完整跟手窗口。触摸由抬起或取消触发回弹，手指保持接触时维持跟手状态。
- 弹簧采用解析步进，阻尼比 ξ = 0.9、角频率 ω = 28 rad/s，按每帧真实时间间隔计算位移和速度，平滑收敛至原位。
- 当 `abs(offset) < 0.3px` 且 `abs(velocity) < 5px/s` 时，位移与速度统一收敛为零并进入正常滚动状态。
- 常规刷新率下，从最后一次 wheel 输入或触摸结束起，位移在500ms内归零；wheel 验收时间包含40ms静默窗口，跟手最长为200ms。

滚动条与弹性解耦。

- 滑块不参与弹性：跟手与回弹期间只反映原生滚动几何，保持常态长度与位置，不压缩、不变透明度。
- 滑块常态高度与位置由正常滚动几何决定，内容长度与视口尺寸变化时同步更新；悬停高光保持120ms外观过渡。
- 弹性位移只作用于位移内容层（`translateY(offset)`）：跟手即时呈现当前输入，回弹逐帧呈现弹簧位置，与滑块绘制互不影响。

历史分页与虚拟高度。

- MessageStream 的上下 spacer 进入正常 scrollHeight，滚动条按虚拟总高度计算滑块位置和长度。
- hasMore=true 且滚动位置进入顶部加载阈值时，StreamScrollbar 触发 `onLoadOlder`；在途请求由历史状态去重。
- 旧历史插入前结束顶部弹性位移并记录锚点，插入后按锚点恢复 scrollTop，随后重新计算滚动条几何。
- hasMore=false 后顶部边界恢复完整的弹性跟手语义；加载失败保留已有内容，并允许用户在同一 cursor 上重试。
- 虚拟块高度变化通过 ResizeObserver 更新总高度，滑块几何在下一动画帧同步，不参与消息投影和分页查询。

状态机。

- IDLE：正常滚动，offset 为零。
- TRACKING：越界跟手，输入持续改变拉力。
- RETURNING：输入结束后按弹簧轨迹归位。
- IDLE → TRACKING：输入朝向滚动边界外。
- TRACKING → RETURNING：wheel 静默窗口结束、同一手势跟手上限到达，或触摸结束。
- RETURNING → TRACKING：新输入从当前弹性位置继续交互。
- TRACKING / RETURNING → IDLE：反向输入抵消拉力并恢复原生滚动，或回弹到达原位。

实现归属。

- Renderer 的 `frontend/src/hooks/useElasticScroll.ts` 负责输入归一化、拉力与回弹状态、动画帧调度；消息流与输出文件列表共用 hook。
- `frontend/src/middle-column/message-stream/StreamScrollbar.tsx` 负责消息流滚动布局、自定义轨道与滑块、滚动几何测量和拖拽交互；消息流通过 `scrollbar-width: none` 与 WebKit 滚动条隐藏样式呈现自定义滑块。
- `frontend/src/components/OutputSidebar.tsx` 为输出文件列表提供同样的布局裁剪层与位移内容层，文件选择和预览沿用现有交互。
- Main 与 IPC 继续提供消息、输出文件与预览数据；滚动输入、弹性状态和逐帧视觉更新由 Renderer 本地完成。

验收标准。

- 顶部与底部连续输入时，内容按对应方向连续跟手，原生滚动范围和边界位置保持稳定；跟手与回弹期间滑块保持常态长度和位置，不随位移变形。
- 短内容支持双向拉动和连续换向，滑块保持可见，并在内容长短变化后同步校正位置与长度。
- 反向输入与回弹中接续输入保持视觉连续，输入余量与原生滚动衔接一致；滚动条拖拽和方向键、翻页键、Home、End 操作接管滚动位置，内容回到正常布局。
- 初始跟手比例为0.24，400px拉力对应48px位移，位移极限为96px；常规刷新率下，最后一次 wheel 输入或触摸结束后500ms内完全归位，wheel 跟手最长200ms（同一手势内，间隔160ms以上视为新手势）。
- 持续越界惯性输入时，位移在约200ms见顶后回落，不被惯性尾巴持续挂住；同一手势内后续事件不再延长位移，新手势重新计时。
- 内容位移在动画帧内沿 transform 合成路径更新；滑块不参与弹性，正常滚动保持原生交互。
