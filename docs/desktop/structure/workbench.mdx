主工作台页面。

- 阅读流：主工作台呈现当前项目或普通范围的一条连续消息流，每次发送创建一次运行；用户通过统一消息流回看该范围历史，活动项目与普通历史范围由 Main 管理。
- 应用外壳：覆盖窗口，左侧容纳导航轨道；工作台内框在导航右侧独立呈现，四周留白、边框、圆角与柔和阴影共同形成抬升层次。
- 左侧导航：位于应用外壳，`I` 进入普通对话，`Project` 展开内框中的项目列表栏；两者沿用各自已有的历史范围。底部齿轮入口进入 Settings 页面，Tooltip 提供入口名称。
- 项目列表栏：位于工作台内框左侧，展示已登记项目，点击条目进入对应项目对话；标题右侧依次提供 `＋` 添加按钮与收起按钮，右边界支持宽度调整。具体布局与交互见[项目导航](../design/workbench/project-navigation.mdx)。
- 标题栏：位于工作台内框顶部，右端提供输出文件、Canvas 和搜索入口，项目列表收起时左端提供展开按钮；消息区与右侧工作侧栏位于标题栏下方。
- 搜索浮层：检索用户消息和最终模型消息；查询需要时通过统一历史分页读取器加载更早的本地会话页，检索对象为本地消息正文。
- Settings 页面：完整接管窗口，左侧提供 Back、General、Providers、Usage 和 TTS，右侧展示对应模块；Back 返回原工作台。Providers 提供列表及刷新、编辑、删除，提供商编辑器包含名称、URL、API Key、模型发现和导入选择；General、Usage 和 TTS 提供模块标题与内容区域。
- 消息主列：位于工作台内框中间的内容行，用户任务、运行耗时与可折叠执行过程、助手正文、消息时间及复制操作在局部视口中滚动。失败信息显示在消息区域。
- Composer：位于内框消息主列底部，提供附件列表、任务输入、模型选择、发送或停止按钮。
- 右侧工作侧栏：位于工作台内框右侧的内容行，输出文件面板与 Canvas 面板共享壳体宽度、拖拽、开合动画和焦点隔离；输出面板提供当前运行的文件列表、文本或图片预览、刷新预览和系统打开操作，Canvas 面板提供当前会话画布与一次性上下文引用。
- 协作：布局、交互和宿主实现边界见[工作台设计](../design/workbench/index.mdx)。
- 源码组织：`frontend/src/workbench/` 按 `navigation`、`project`、`settings/general`、`settings/providers`、`titlebar/search` 和 `output` 组织功能，页面壳体位于对应父目录，业务组件、局部样式、专属 Hook 和状态按功能归属组织；消息主列归属 `frontend/src/middle-column/`，运行与历史状态归属 `frontend/src/store/`，全局样式与颜色令牌由 `frontend/src/styles.css` 统一维护。
- 共享能力：`frontend/src/shared/` 按 `ui`、`preferences`、`i18n`、`scroll` 和 `sidebar` 提供跨功能能力；界面偏好与文案分别以共享偏好模块和文案表为单一来源，设置页与各功能通过统一入口读取和更新。
