主工作台页面。

主工作台呈现一条连续消息流，每次发送创建一次运行，消息流跨运行和后台会话累积；用户通过统一消息流回看历史，后台会话由 Main 管理。

- 标题栏（右上角悬浮按钮组）：输出文件侧边栏开关、Canvas、搜索入口、设置入口。固定悬浮于窗口右上角，不绘制独立背景条；消息主列与共享右侧工作侧栏都纵向贯穿窗口全高，顶部52px透明拖拽层悬浮在内容之上。
- 搜索浮层：检索用户消息和最终模型消息；查询需要时通过统一历史分页读取器加载更早的本地会话页，不是文件搜索或远程搜索。
- 设置面板：提供商列表及刷新、编辑、删除；提供商编辑器包含名称、URL、API Key、模型发现和导入选择。
- 消息主列：用户任务、运行耗时与可折叠执行过程、助手正文、消息时间及复制操作。失败信息显示在消息区域。
- Composer：附件列表、任务输入、模型选择、发送或停止按钮。
- 右侧工作侧栏：输出文件面板与 Canvas 面板共享壳体宽度、拖拽、开合动画和焦点隔离；输出面板提供当前运行的文件列表、文本或图片预览、刷新预览和系统打开操作，Canvas 面板提供当前会话画布与一次性上下文引用。

布局、交互和宿主实现边界见[工作台设计](../design/workbench/index.mdx)。
