# 组件视觉规则

## Header

- 高度 `56px`，背景使用 `--color-surface`，底部一条低对比度分隔线。
- 左侧显示当前任务标题，右侧依次是搜索和设置图标按钮。
- 运行状态使用紧凑文字 + 语义图标，不使用整条彩色背景。

## Search popover

- 宽度 `320–420px`，使用 `--color-surface`、`--radius-md` 和轻阴影。
- 搜索输入、匹配数量、上下跳转和空结果说明在同一层级内排列。
- 匹配结果使用 accent 低透明度背景，当前匹配使用清晰边界。

## Settings drawer

- 默认宽度 `360px`，从右侧打开；窄窗口占满可用宽度。
- 分组顺序：模型连接。
- 字段高度 `40px`；标签使用 `--color-text-secondary`；错误字段使用 `--color-danger`。
- 抽屉动画使用 `180ms ease-out`；减少动画模式下取消位移动画。

## Composer

- 固定在对话流底部，最小高度 `56px`，上下留出 `16px` 内边距。
- 左侧是 `Plus` 入口，中间是多行输入，右侧是发送或停止主按钮。
- 输入获得焦点时只显示一层 accent focus ring。
- 运行中停止按钮使用中性或 danger 语义，但必须显示“正在停止”过渡状态。

## Conversation stream

- 用户任务、模型正文、内联活动流和最终回答使用文字层级与留白区分，不使用一组独立卡片切割消息流。
- `Working for + 运行时长` 使用文字字形扫光。文字内容与位置保持静止，仅让带柔和边缘的高亮渐变从左向右穿过字符笔画。
- 扫光渐变必须通过 `background-clip: text` 限制在文字字形内部，不得影响摘要行背景、展开箭头、分隔线或相邻正文。
- 扫光使用 `--color-text-shimmer-base`、`--color-text-shimmer-highlight`、`--text-shimmer-band-width`、`--text-shimmer-track-size`、`--motion-text-shimmer` 和 `--ease-text-shimmer`。不为同一效果创建组件私有色值或时长。
- 渐变轨道必须使用 `background-repeat: no-repeat`。关键帧从 `background-position: 100% 0` 移动到 `0% 0`，确保高光在每一轮开始前位于文字左侧之外，结束后位于文字右侧之外。
- 动画循环只能在高光完全离开字形后重置。每一轮必须完整穿过全部文字，不得因背景平铺、半程重置或裁剪边界而中途消失。
- 运行结束后状态改为静态 `Worked for + 总时长`；减少动态效果模式下取消扫光，使用 `--color-text-shimmer-base` 显示静态文字。
- 运行过程直接插入当前回答的正文流，不使用封闭边框、圆角背景或阴影形成外层卡片。
- 模型进度说明保持普通正文排版；搜索、读取、编辑文件和执行命令等行为使用低强调的“图标 + 动作摘要 + 可选耗时”单行展示。
- 多个连续工具调用收敛为一条可展开的工具组摘要。展开工具组后按时间顺序显示各次调用；单次调用可以再次展开参数、命令、状态、返回码和输出。
- 活动层级只通过留白、缩进、图标、文字层级和细分隔线表达。命令和输出使用 `--font-mono`。
- 最终回答使用最高文本层级；鼠标悬停或键盘聚焦回答后显示复制动作和回复时间。

## Responsive

- `≥ 900px`：居中内容列，设置抽屉覆盖内容。
- `640–899px`：标题栏只显示搜索和设置图标，内容列保持可读宽度。
- `< 640px`：设置抽屉全宽，执行详情默认收起，按钮热区保持 `40px`。
