# Agent Studio 组件视觉规范

本文是 Agent Studio 唯一的视觉设计规范。规范以组件为单位组织；每个组件章节都包含自身的内容结构、颜色、字体、间距、尺寸、图标、状态、动效、无障碍和响应式规则，可以脱离其他章节直接实现。

图标使用 SF Symbols 语义名称作为设计契约。HTML/Electron 原型不能直接渲染 SF Symbols 时，使用同义的线性 SVG 路径实现，但不得改变图标语义、尺寸或笔画风格。

## Header

### 结构与尺寸

- 高度 `56px`。
- 背景 `#202125`；底部使用 `1px solid rgba(255, 255, 255, 0.11)` 分隔线。
- 左侧显示当前任务标题和运行状态；右侧依次显示搜索和设置入口。
- 标题最大占用可用宽度，溢出使用省略号，不推动右侧操作区换行。
- 内容水平内边距 `16px`；操作按钮之间间距 `4px`。

### 字体与颜色

- UI 字体：`"JetBrains Mono", "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", sans-serif`。
- 当前任务标题：`14px / 20px`，字重 `560`，颜色 `#f4f4f5`。
- 运行状态：`12px / 18px`，颜色 `rgba(244, 244, 245, 0.46)`。
- 状态不能只依赖颜色，必须同时显示文字和语义图标。

| --- | --- | ---: | ---: | --- |
| 搜索当前运行 | `magnifyingglass` | 18px | 40×40px | 搜索当前运行 |
| 打开设置 | `gearshape` | 18px | 40×40px | 设置 |
| 待命 | `circle` | 12px | — | 待命 |
| 运行中 | `circle.dotted` | 12px | — | 正在运行 |

- 图标按钮默认颜色 `rgba(244, 244, 245, 0.72)`；悬停或聚焦时颜色 `#f4f4f5`，背景 `rgba(255, 255, 255, 0.06)`。
- 过渡时长 `180ms`，缓动 `cubic-bezier(0.22, 1, 0.36, 1)`。
- `640–899px` 仅保留搜索和设置图标，不显示长标题；`< 640px` 保持 `40px` 热区。

## Search popover

### 结构与尺寸

- 宽度 `320–420px`，窄窗口使用 `calc(100vw - 24px)`。
- 与标题栏顶部保持 `4px` 间距；内边距 `12px`。
- 背景 `#202125`，圆角 `12px`，边框 `1px solid rgba(255, 255, 255, 0.11)`。
- 阴影 `0 12px 32px rgba(0, 0, 0, 0.28)`。
- 搜索输入高度 `40px`；结果区域、匹配数量、上一个/下一个和空结果说明在同一浮层内排列。

### 字体与颜色

- 输入和结果字体：`"JetBrains Mono", "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", sans-serif`；输入 `14px / 20px`，匹配计数 `12px / 18px`。
- 输入文字 `#f4f4f5`；Placeholder `rgba(244, 244, 245, 0.46)`；辅助文字 `rgba(244, 244, 245, 0.46)`。
- 匹配背景 `rgba(120, 169, 255, 0.16)`；当前匹配使用 `1px solid #78a9ff`，不能只依靠背景颜色表达。

### 图标与交互状态

| 用途 | SF Symbol 语义名 | 尺寸 | 热区 | `aria-label` / Tooltip |
| --- | --- | ---: | ---: | --- |
| 搜索 | `magnifyingglass` | 18px | 40×40px | 搜索当前运行 |
| 上一个匹配 | `chevron.up` | 16px | 40×40px | 上一个匹配 |
| 下一个匹配 | `chevron.down` | 16px | 40×40px | 下一个匹配 |
| 关闭浮层 | `xmark` | 16px | 40×40px | 关闭搜索 |

- 打开后焦点进入输入框；`Enter` 定位下一个匹配，`Shift + Enter` 定位上一个匹配，`Esc` 关闭并将焦点返回搜索按钮。
- 流式新增内容进入当前运行索引后，匹配数量实时更新。
- 浮层动画 `180ms cubic-bezier(0.22, 1, 0.36, 1)`；减少动态效果时取消位移动画，只保留显示状态变化。

## Settings drawer

### 结构与尺寸

- 默认宽度 `360px`；窄窗口使用 `100vw`。
- 从右侧覆盖消息流打开，不改变主内容列宽度。
- 背景 `#202125`；左边框 `1px solid rgba(255, 255, 255, 0.11)`；抽屉内容内边距 `16px`。
- 当前分组为“模型连接”：Provider、Model、Base URL、API Key。
- 字段高度 `40px`；字段间距 `16px`；标签与输入框间距 `6px`。

### 字体与颜色

- 标题 `16px / 24px`，字重 `600`，颜色 `#f4f4f5`。
- 分组标题 `12px / 18px`，颜色 `rgba(244, 244, 245, 0.46)`。
- 标签 `12px / 18px`，颜色 `rgba(244, 244, 245, 0.72)`。
- 输入文字 `14px / 20px`，颜色 `#f4f4f5`；输入背景 `#1d1e22`；边框 `rgba(255, 255, 255, 0.11)`；圆角 `8px`。
- 校验错误使用 `#f28b82` 和错误图标，并同时显示文字原因；不能只依赖红色边框。

### 图标与交互状态

| 用途 | SF Symbol 语义名 | 尺寸 | 热区 | `aria-label` / Tooltip |
| --- | --- | ---: | ---: | --- |
| 关闭抽屉 | `xmark` | 16px | 40×40px | 关闭设置 |
| 字段错误 | `exclamationmark.circle` | 16px | — | 配置错误 |
| 显示/隐藏 API Key | `eye` / `eye.slash` | 16px | 40×40px | 显示 API Key / 隐藏 API Key |

- 打开动画 `180ms ease-out`；关闭、`Esc` 和点击外部区域均可退出。
- 运行中字段只读，显示“当前运行配置已锁定”；未发送的配置草稿在关闭后保留。
- 焦点环为 `2px solid #78a9ff`，外扩 `2px`；减少动态效果时取消位移动画。

## Composer

### 结构与尺寸

- 固定在消息流底部，最小高度 `56px`，上下内边距 `16px`。
- 输入容器最大宽度 `780px`，水平居中；背景 `#202125`；边框 `1px solid rgba(255, 255, 255, 0.11)`；圆角 `12px`。
- 左侧为添加文件入口，中间为多行输入，输入区下方放置模型选择；右侧为发送或停止主按钮。
- 输入正文 `14px / 22px`；最少显示两行，内容增长时容器自然增高但不覆盖发送按钮。

### 颜色与字体

- 输入文字 `#f4f4f5`；Placeholder `rgba(244, 244, 245, 0.46)`。
- 控件辅助文字 `12px / 18px`，颜色 `rgba(244, 244, 245, 0.72)`。
- 主发送按钮背景 `#78a9ff`，前景 `#17181b`；停止按钮背景 `#1d1e22`，边框 `rgba(244, 244, 245, 0.46)`。
- 输入获得焦点时只显示一层 `2px solid #78a9ff` focus ring，不能叠加多层阴影。

### 图标与交互状态

| 用途 | SF Symbol 语义名 | 尺寸 | 热区 | `aria-label` / Tooltip |
| --- | --- | ---: | ---: | --- |
| 添加文件 | `plus` | 18px | 40×40px | 添加文件 |
| 发送 | `arrow.up` | 18px | 40×40px | 发送 |
| 停止 | `square` | 16px | 40×40px | 停止运行 |
| 选择模型 | `chevron.down` | 14px | 40×40px | 选择模型 |
| 移除附件 | `xmark` | 14px | 40×40px | 移除附件 |

- 任务为空时发送按钮不可用；`Enter` 发送，`Shift + Enter` 换行；中文输入法组合态的 `Enter` 不得提交。
- 添加文件后显示文件名和移除入口；上传能力未连接时入口仍保留清晰禁用态，不伪造成功结果。
- 运行中箭头切换为方形停止图标；点击后先显示“正在停止”，禁用重复发送，直到收到取消完成事件。
- 主按钮图标与文字状态同时表达语义；纯图标按钮必须提供 Tooltip 和 `aria-label`。

## Conversation stream

### 结构与尺寸

- 内容列最大宽度 `760px`，水平居中；桌面端左右留白 `24px`，窄窗口使用 `16px`。
- 用户任务、模型正文、内联活动流和最终回答共享一条垂直阅读流，不使用外层卡片、封闭背景块或阴影分割。
- 用户任务使用最大 `76%` 宽度的右对齐气泡；模型内容使用普通正文宽度，不显示 `Step 1` 等回合编号。
- `Working for / Worked for` 摘要行高度约 `32px`，下方使用 `1px solid rgba(255, 255, 255, 0.11)` 分隔线；摘要右侧为 `chevron.right`。
- 内联活动行使用 `5px 0` 垂直间距；工具组展开后左侧缩进 `20px`，使用 `1px solid rgba(255, 255, 255, 0.11)` 竖向关系线。

### 字体与颜色

- 模型正文：`15px / 28px`，颜色 `rgba(244, 244, 245, 0.87)`。
- 活动摘要：`13px / 20px`，颜色 `rgba(244, 244, 245, 0.46)`；动作名称使用 `rgba(244, 244, 245, 0.72)`。
- 命令与输出：`12px / 19px`，使用 `"SF Mono", ui-monospace, Menlo, monospace`。
- 最终回答：`15px / 28px`，颜色 `#f4f4f5`；回复时间和复制动作颜色 `rgba(244, 244, 245, 0.46)`。

### 图标与内联层级

| 用途 | SF Symbol 语义名 | 尺寸 | `aria-label` / Tooltip |
| --- | --- | ---: | --- |
| 展开/收起运行详情 | `chevron.right` | 16px | 展开详情 / 收起详情 |
| 工具组 | `wrench.and.screwdriver` | 16px | 工具调用 |
| 搜索 | `magnifyingglass` | 16px | 搜索 |
| 读取文件 | `doc.text` | 16px | 读取文件 |
| 编辑文件 | `pencil` | 16px | 编辑文件 |
| 执行命令 | `terminal` | 16px | 执行命令 |
| 创建文件 | `doc.badge.plus` | 16px | 创建文件 |
| 复制回答 | `square.on.square` | 16px | 复制回答 |

- `Working for + 运行时长` 使用文字字形扫光。文字与位置保持静止，只有字形内部的渐变移动。
- 字形扫光使用 `background-clip: text`、`background-repeat: no-repeat`；渐变轨道从 `100% 0` 匀速移动到 `0% 0`，每轮必须完整穿过所有字符后才在不可见区域重置。
- 字形扫光的基础色为 `rgba(244, 244, 245, 0.46)`，高光色为 `rgba(244, 244, 245, 0.92)`，高光带宽 `12%`，轨道尺寸 `250% 100%`，一次完整扫过 `3000ms`，缓动 `linear`。
- 运行结束后改为静态 `Worked for + 总时长`，不再播放扫光；减少动态效果时只显示基础色静态文本。
- 第一层展开显示模型进度和工具组摘要；第二层展开显示单次工具调用；第三层仅在需要时显示参数、命令、工作目录、状态、返回码和输出。
- 工具活动通过留白、缩进、图标、文字层级和细分隔线表达，禁止使用外层卡片、封闭背景、圆角容器或阴影制造隔离感。

### 状态与交互

- 空闲时展示已有对话历史。
- 运行中默认展开第一层活动流；运行结束后默认收起，但记录用户主动展开的状态。
- 活动事件按时间顺序追加；前端只能消费结构化事件，不能从模型正文猜测工具类型。
- 模型回答悬停或键盘聚焦时，在回答下方显示复制图标和 `AM/PM` 本地时间；不显示 `Copy` 文案。
- 搜索命中折叠详情时可临时展开上下文，搜索结束后恢复用户原有折叠偏好。
- 用户位于流底部时跟随最新内容；主动向上阅读时暂停抢焦点，并提供“回到最新”入口。
