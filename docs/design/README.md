# Agent Studio Design

这里是视觉层的唯一来源，不按 PM / UX / UI 角色拆分。

- `icons.md`：动作到图标的映射、尺寸和无障碍标签。
- `components.md`：Header、搜索浮层、设置抽屉、消息流和 composer 的视觉规则。
- `../../designs/agent-studio/index-v2.html`：当前消费这些规则的可交互原型。
- `../../designs/agent-studio/index.html`：旧版状态演示，仅作视觉对照。

产品内容见 `../product-structure/`；交互逻辑见 `../interaction/`。
